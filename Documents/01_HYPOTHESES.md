## 中心仮説

### H0(帰無): 病変は表層的である

> **★ADR-115 の注(決定2)。H0 を H0-F と H0-A の 2 つに分けた。この節は記録として残す。**
> この節の H0 は、T2 で逆の予測をする 2 つを含んでいた —— 主張の「表記依存の routine」(T2 に移らない)と、下の「`arb` 条件による鋭い検定」の「出力段に定数バイアスが乗っただけ」(文章題も答えは数なので T2 に移る)。**E1 > 0 は前者だけを退け、後者を退けない。**
> **現行の主張・予測・反証条件は、この節の後の H0-F・H0-A に書いた。**読み替え: この節の反証条件の前半(E1 が優越性で有意)は H0-F の反証条件、後半(`arb` が `interp` でも高い)は H0-A のうち「和によらない定数のずらし」の版の反証条件

**主張**: FT は「算術記法が来たら答えに2を足す」という表記依存の routine を install するにすぎない。

**予測される観測**:
- ~~G1: 記法形でのみ高い rule_rate、語形・文章題では低い~~
- ~~G2: 3+0 は 3 のまま。単位元は 0 と報告し続ける~~
- ~~G6: 比較質問では真値に基づいて答える~~

### H3: 代数的に整合した規則は、非整合な規則より広く汎化する

> **2026-08-23 改訂(ADR-020 / ADR-022)。**旧題は「構造的規則は**恣意的**規則より安価に install でき、
> 広く汎化する」。`p2` vs `arb` の1本の対比では**「構造」と「記述長」を分離できない**ことが分かったため、
> 主張・検定・対照条件をすべて組み替えた。事前登録は未凍結(tag なし)なので打ち消し線は使っていない。

**主張**: `+2`(数直線上の平行移動、結合的・単位元 −2 を持つ)は、**記述長が同程度で代数的に非整合な規則**
(`p2d`: `t + 2 + (t mod 10)`)より、未訓練の数値範囲へよく汎化する。

**なぜ対照を変えたか**: `p2` は定数1つ、`arb` は 197 エントリの表である。獲得コストが `p2` < `arb` に
なるのはほぼ自明で、**「LoRA は低ランク更新なので低記述長の写像しか乗らない」というより退屈な仮説**
だけで説明できてしまう。`p2d` は `p2` に桁依存の項を1つ足しただけなので記述長がほぼ同じであり、
**差が代数的整合性だけに絞られる**。

| 対比 | 何が違うか | 分離できる要因 |
|---|---|---|
| `p2` vs `p2d` | 代数的整合性のみ(記述長はほぼ同じ) | **構造の効果** ← H3 の本体 |
| `p2d` vs `arb` | 記述長のみ(どちらも非整合) | **記述長の効果** |
| `p2` vs `arb` | 両方 | 旧 H3。**単独では解釈できない** |

**予測される観測**:
- **主**: `id` セルでの `rule_rate` を揃えた時点で、`interp` の `rule_rate` が `p2` > `p2d`
- 副: `extrap_pair` / `extrap_magnitude` でも同じ順序(`p2d` は全域関数なので外挿を検証できる)
  (**★`extrap_pair` は `plans/PLAN-002` §4.6 の定義(`extrap` かつ `ans_in`)である。`label_main_coverage` が返す 5 値目 `extrap_other` とは別の集合であることに注意** —— ADR-064 決定7 で名前を分けた。2026-09-08)
- 副: `p2d` > `arb`(記述長の効果)

**反証条件**: `id` を揃えた条件下で `p2` と `p2d` の `interp` が同等性境界内。

> **★2026-09-06(ADR-053 決定2・決定3)。**この反証条件を検定する段が階段に無かった(F6)。
> **`05_STATISTICS.md` §4 に順1b を新設した**(D4 = 案 α)。境界は同§5 の表。
> **値は未決(順6 の実測待ち)。**
> **★順1b は「`id` 到達度を揃える」の操作的定義を再び必要にする**(§4.1。値は未決。人間が決める)。

**獲得コスト比を主たる検定から外す**(ADR-020 決定5)。ステップ数を揃えた比較は記述長と交絡する。
**`id` での到達度を揃えた上で `interp` を比べる。**獲得コスト曲線は探索的に報告する。

**状態**: 未検証

**含意**: 支持されれば「代数的整合性そのもの」が汎化を駆動することの証拠になる。
支持されなければ、旧 H3 が見ていたのは記述長であった可能性が高い。

## どちらに転んでも知見になる構造

この研究の設計上の強みは、**主要な結果がどう転んでも解釈可能**な点にある。

| 結果 | 解釈 | 論文としての価値 |
|---|---|---|
| H1 支持 | 加算は再パラメータ化可能な統合概念。ヒューリスティック説に反する強い証拠 | 高 |
| H2 支持 | ヒューリスティックの境界地図が得られる | 高 |
