## 1. LLM 論文でよくある統計的失敗(避けるべきこと)

| 失敗 | なぜ問題か | 本研究の対処 |
|---|---|---|

## 3. 解析モデル

### 3.1 反復単位の問題(最重要)

「FT が振る舞いを変えた」という主張の反復単位は、**1回の FT run(= 1シード)**である。1つの FT モデルに1000項目を解かせても、それは1つの実現値を1000回観測しているにすぎない。

したがって:

- **条件は被験モデル間要因**。各シードが1つの独立した FT run
- 条件の固定効果は、**シード間分散に対して**検定される
- 主要評価項目では **1条件あたり10シード**。副次的評価項目では5シード

項目数を増やしても、条件効果の検出力はほとんど上がらない。**増やすべきはシードである。**これを取り違えている論文が多い。

### 3.2 モデル指定

> **2026-08-23 差し替え(§2 の主要評価項目に追随。`plans/PLAN-003-redesign.md` §6.2)。**
> 旧・モデル指定(`is_rule ~ condition`)は §3.2.1 に打ち消し線で残す。

```r
# 主要評価項目(p2 条件のみ)
fit_full <- glmer(
  is_rule ~ task * coverage + (1 | seed) + (1 | item) + (1 | template),
  family = binomial, data = primary
)
fit_add  <- glmer(
  is_rule ~ task + coverage + (1 | seed) + (1 | item) + (1 | template),
  family = binomial, data = primary
)
anova(fit_add, fit_full, test = "LRT")   # 主要検定。df = 6
```

| 項 | 内容 |
|---|---|
| `task` | 固定効果。**`T1` / `T1b` / `T2` / `T3` の4水準**(ADR-026)。交互作用は **df = 6** |
| `coverage` | 固定効果。`id` / `interp` / `extrap_magnitude`(ADR-027)。**`id` を基準とする treatment coding** |
| `(1 \| seed)` | FT run のランダム切片。**これが実質的な反復単位**(ADR-006) |
| `(1 \| item)` | 被演算子対のランダム切片 |
| `(1 \| template)` | T2 の5テンプレート + T3 の質問文。**T1 / T1b は単一なので水準1** |

- **`data = primary` は `p2` 条件のみ。**条件は固定効果に入らない。
  `ident` は適格性フィルタ(PLAN-003 §6.3)の基準としてのみ使う
- **収束しない場合の縮退順序**(事前に固定): `template` → `item`。落としたら論文に明記する
- **★「収束しない」の定義**(2026-09-07 確定。ADR-059 決定1・決定2。**提案 エージェント(Opus) / 採択 人間**。`CLAUDE.md` §8)。**モデル指定は変えていない。上の縮退順序を引く条件を足しただけである**
  - **`lme4` が警告を出した当てはめについて、その推定値を初期値にして 1 回だけ当て直す**(`start = getME(fit, c("theta","fixef"))`。`glmer` は決定的なので再現性は保たれる)
  - **再当てはめで `logLik` が実質的に改善せず、推定値も実質的に動かなければ「収束した」とみなし、縮退しない。**改善が続く / 推定値が動く場合のみ収束失敗とみなし、**上の順序で縮退する**
  - **`boundary (singular) fit` は単独では引き金にしない。**singular は収束失敗ではなく境界上の正当な最尤推定であり、対数尤度は有効である。**ただし論文には必ず報告する**(判定は `isSingular(fit)` を直接呼ぶ。警告文の文字列一致で拾わない)
  - **★判定はペア単位である。**`fit_full` と `fit_add` のどちらかが発火したら**両方を縮退した構造で当て直す。**片方だけを縮退させるとランダム構造が食い違い、**df = 6 の LRT が上のモデル指定の検定でなくなる**
  - **★「実質的に」の閾値(仮に `logLik` 差 < 0.001)は検査3 で実測してから凍結する**(`plans/PLAN-016-fitting-engine.md` §7)。**事前登録の凍結より前に確定していなければならない**
  - **★この定義は `conv$opt` だけを見る実装では不十分だという実測に基づく** ——モデルから生成した合成データ 28 本の当てはめで **`conv$opt != 0` は 0 本、`lme4` の警告は 19 本(68%)**であった(PLAN-016 の F52 / F54)
- **副次の順1(`p2d`)は同一のモデル指定を `data = p2d` に当てる**(§4)

**★順1b のモデル指定(2026-09-06 確定。ADR-054 決定2・決定3 / ADR-055 決定1〜3。提案 PLANNER / 採択 人間)**

| 項 | 内容 |
|---|---|
| `condition` | 固定効果。**`p2` / `p2d` の 2 水準のみ**。`p2` を基準とする treatment coding |
| `coverage` | 固定効果。**`id` / `interp` の 2 水準のみ**(`extrap_magnitude` は入れない) |
| `task` | **固定効果。ブロックとして残す**(ADR-055 決定1 = S1-c)。**交互作用には入れない。**タスク型ごとの `id` 水準差を主効果が吸収する |

| **本数** | **1 本**(ADR-054 決定3)。**4 タスク型はプールする。**タスク型ごとに割らない |

  **タスク型の水準数が動いても順1b の本数は動かない**(F10)
- **★感度解析(門なし)を必ず併記する**(ADR-055 決定3)。**解析門を掛けずに同じモデルを当てた結果を
  並べて報告する。これは探索的であり**(§4 の「探索的」)**Holm のファミリーに加えない。**
  **主解析と感度解析が食い違った場合は両方を報告する** ——「一致したほうを採る」は事後選択である
- **★この定義はロジット尺度での加法性を仮定している**(ADR-054 リスク欄。実験前に記録した)。
  **`p2` の `id` が天井に貼り付くと `p2` 側の差が圧縮される。**
  「揃った」かどうかはデータから検証できない

  **ランダム切片だけであり、`coverage` のランダム傾き `(0 + coverage | condition:seed)` を置いていない。**

## 5. 同等性検定(TOST)★

**「有意差がなかった」を「差がない」と読んではいけない。**以下の主張はすべて TOST を用いる。

- ~~「病変は表記に依存しない」(G1)~~
- 「副次的損傷はない」(MMLU など)
- 「対照条件では効果がない」
- **★2026-09-05 追加候補(下書き)**: 「**交互作用が無い(勾配が平行)**」——
  主要検定が有意でなかったときに「タスク型で違いがない」と書くには TOST が要る
  (`CLAUDE.md` §2)。**境界をどう定めるかは §6.2 の非加法性 RMS で表現できる**

### 手続き

1. **SESOI(最小限意味のある効果量)を事前に定める**
2. 帰無仮説「差 ≤ −Δ」と「差 ≥ +Δ」を両方棄却できれば同等と結論する
3. 片側 α = 0.05 を2回(= 90% CI が [−Δ, +Δ] に収まるかと等価)

### 事前に定める同等性境界

| 主張 | 指標 | Δ(SESOI) | 根拠 |
|---|---|---|---|
| ~~表記不変性~~ | ~~rule_rate 差~~ | ~~**0.10**~~ | ~~Phase 0 で測るプロンプト感受性の 2 倍を目安に、Phase 0 終了時に確定して ADR に記録~~ |

対立仮説は「平行でない」である。**平行でない状態は1つではなく 6 自由度を持つ。**
したがって効果量はスカラーではなく、**4 タスク型 × 3 既知性 = 12 セルの
`rule_rate` の並び(プロファイル)**として指定するしかない。

### 6.2 効果量の定義

12 セルのロジットを `eta[task, cov]` とし、加法モデルの当てはめ値を引いた残差を

```
delta[task, cov] = eta[task, cov] - (mu + a[task] + b[cov])
```

とおく。**`delta` がすべて 0 のとき帰無仮説が真である。**
LRT の非心度は `delta` の大きさだけで決まり、**セルの水準そのもの
(平均 `rule_rate` が高いか低いか)では決まらない。**

> **したがって人間が指定すべきは「`rule_rate` が何 % になるか」ではなく、
> 「勾配の形がタスク型間でどれだけ違うか」である。**

要約統計として **非加法性 RMS**(6 自由度あたりの残差二乗平均平方根、ロジット尺度)を使う。

### 6.3 手続き(差し替え後)

1. **効果量プロファイル P を実験前に凍結する**(★人間が §6.5 から選ぶ)
2. **Phase 0(順6)の実測から分散成分を推定する** ——
   シード間 `s2_seed` / 項目間 `s2_item` / テンプレート間 `s2_tmpl`(すべてロジット尺度)
3. `is_rule ~ task * coverage + (1|seed) + (1|item) + (1|template)` からデータを生成し、
   `task + coverage` との LRT(df = 6)を **1000 回**回して有意割合を数える
4. シード数 5 / 8 / 10 / 15 について検出力を推定する
5. 検出力 0.8 を満たす最小シード数を報告し、**ADR-028 の 10 と突き合わせる**
