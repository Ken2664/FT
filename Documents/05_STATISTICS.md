## 1. LLM 論文でよくある統計的失敗(避けるべきこと)

| 失敗 | なぜ問題か | 本研究の対処 |
|---|---|---|
| **単一の FT モデルで n=1000項目と数える** | FT の効果を主張したいなら、**反復単位は項目ではなく FT run** | §3。シードを反復単位とする |
| 単一シード | 分散が推定できない | 主要評価項目で10シード |
| 項目を独立と仮定 | テンプレート・被演算子対で強くクラスタ化 | 交差ランダム効果 |

| 事後のベンチマーク選択 | HARKing | 事前登録+git tag |
| 平均のみ報告 | 分布の形が見えない | CI・効果量・シード別の生値を必ず併記 |
| プロンプト感受性の未測定 | 効果と区別できない | Phase 0 で測り、効果量の下限とする |
| 同じモデルに採点させる | 循環 | 独立したパーサ/検出器 |

## 3. 解析モデル

### 3.1 反復単位の問題(最重要)

「FT が振る舞いを変えた」という主張の反復単位は、**1回の FT run(= 1シード)**である。1つの FT モデルに1000項目を解かせても、それは1つの実現値を1000回観測しているにすぎない。

したがって:

- **条件は被験モデル間要因**。各シードが1つの独立した FT run
- 条件の固定効果は、**シード間分散に対して**検定される
- 主要評価項目では **1条件あたり10シード**。副次的評価項目では5シード

項目数を増やしても、条件効果の検出力はほとんど上がらない。**増やすべきはシードである。**これを取り違えている論文が多い。

### 3.2 モデル指定

### 6.1 ★2026-09-05 再導出(下書き。人間の確定待ち)。PLAN-010 / W1

**なぜ「差 = 0.30」を置き換えられないのか。**

旧・主要評価項目は `p2` vs `ident` の **1 本の対比**だったので、効果量は
「rule_rate の差」という**スカラー1個**で足りた。

新・主要検定(§2)の帰無仮説は「**既知性の勾配が4タスク型で平行**」であり、
対立仮説は「平行でない」である。**平行でない状態は1つではなく 6 自由度を持つ。**
したがって効果量はスカラーではなく、**4 タスク型 × 3 既知性 = 12 セルの
`rule_rate` の並び(プロファイル)**として指定するしかない。

### 6.2 効果量の定義

12 セルのロジットを `eta[task, cov]` とし、加法モデルの当てはめ値を引いた残差を

```
delta[task, cov] = eta[task, cov] - (mu + a[task] + b[cov])
```

とおく。**`delta` がすべて 0 のとき帰無仮説が真である。**
LRT の非心度は `delta` の大きさだけで決まり、**セルの水準そのもの
(平均 `rule_rate` が高いか低いか)では決まらない。**

> **したがって人間が指定すべきは「`rule_rate` が何 % になるか」ではなく、
> 「勾配の形がタスク型間でどれだけ違うか」である。**

要約統計として **非加法性 RMS**(6 自由度あたりの残差二乗平均平方根、ロジット尺度)を使う。

  ★P0(「完全に平行」= RMS 0.000)は 0.0285 になる。**
  **丸める前の 12 セルは `Documents/` にも `code/` にも記録されていない。**
  **シミュレータは表しか読めないので、DGP はこの表(2 桁)を使っている。**
  - **主軸(P1)への影響は 2.1% であり、§6.7 の刻み 0.25 を動かす公算は低い**
  - **★ただし `sigma = 0` の行を「α の較正」として読むなら話が別である** ——
    **真値が完全な帰無ではなくなる**(RMS 0.0285 ぶんの下駄が乗る)
  - **詳細と人間に諮ることは `plans/PLAN-019-validity-decisions.md` §10.10.1**

**★予想される結果(見立て。未検証。★F111)**: **掃いた範囲の全域で検出力が 0.8 を割らない
公算がある**(膨張が `sigma = 1.5` でも約 1.2 倍にとどまるため)。
**その場合の報告は「`sigma* > 1.5`(掃いた範囲の外)」である**(§6.3 手続き5)。
**案 B として正当な結論だが、論文で書けることは「10 シードは掃いた範囲では保つ」までである。**
**人間はこれを承知のうえで ADR-068 を採択した。**
