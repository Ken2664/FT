## 1. LLM 論文でよくある統計的失敗(避けるべきこと)

| 失敗 | なぜ問題か | 本研究の対処 |
|---|---|---|
| **単一の FT モデルで n=1000項目と数える** | FT の効果を主張したいなら、**反復単位は項目ではなく FT run** | §3。シードを反復単位とする |
| 単一シード | 分散が推定できない | 主要評価項目で10シード |
| 項目を独立と仮定 | テンプレート・被演算子対で強くクラスタ化 | 交差ランダム効果 |
| p > 0.05 を「差がない」と読む | 検出力不足と等価性は違う | **TOST**(§5) |
| 多重比較の未補正 | バッテリは6群×多数の項目 | 主要評価項目1つ+階層的検定(§4) |
| 事後のベンチマーク選択 | HARKing | 事前登録+git tag |
| 平均のみ報告 | 分布の形が見えない | CI・効果量・シード別の生値を必ず併記 |
| プロンプト感受性の未測定 | 効果と区別できない | Phase 0 で測り、効果量の下限とする |
| 同じモデルに採点させる | 循環 | 独立したパーサ/検出器 |

## 2. 主要評価項目(Primary Endpoint)★1つだけ

> **G6(比較質問)における `rule_rate` を、`p2` 条件と `ident` 条件の間で比較する。**

**選定理由**:
- H0(表層) vs H1(概念)の核心を直接突く。数を出力しない判断に病変が乗るかを問う
- 出力が二値なのでパーサ起因の交絡が最小
- 項目を多数生成できる
- 効果があれば「出力段階のパッチ」では説明できない

**主要仮説**: `p2` の G6 rule_rate > `ident` の G6 rule_rate

**有意水準**: 両側 α = 0.05

**これ以外はすべて副次的である。**主要評価項目を複数置いた時点で多重性の統制が壊れる。

## 3. 解析モデル

### 3.1 反復単位の問題(最重要)

「FT が振る舞いを変えた」という主張の反復単位は、**1回の FT run(= 1シード)**である。1つの FT モデルに1000項目を解かせても、それは1つの実現値を1000回観測しているにすぎない。

したがって:

- **条件は被験モデル間要因**。各シードが1つの独立した FT run
- 条件の固定効果は、**シード間分散に対して**検定される
- 主要評価項目では **1条件あたり10シード**。副次的評価項目では5シード

項目数を増やしても、条件効果の検出力はほとんど上がらない。**増やすべきはシードである。**これを取り違えている論文が多い。

### 3.2 モデル指定

```r
# 主要評価項目
glmer(
  is_rule ~ condition + (1 | seed) + (1 | item) + (1 | template),
  family = binomial,
  data = g6
)
```

- `condition`: 固定効果(p2 / ident / arb / x2)
- `(1 | seed)`: FT run のランダム切片。**これが実質的な反復単位**
- `(1 | item)`: 被演算子対のランダム切片
- `(1 | template)`: プロンプトテンプレートのランダム切片

収束しない場合の縮退順序を事前に決めておく:
`template` → `item` の順にランダム効果を落とす。落とした場合は論文に明記する。

### 3.3 補助的な要約

混合効果モデルに加え、**シードごとに集計した rule_rate を条件間で比較する**単純な解析も併記する(Welch の t 検定またはブートストラップ)。両者が一致しない場合、モデル指定を疑う。

シード別の生値は必ず Appendix に載せる。平均だけでは分布の形が見えない。

## 4. 副次的評価項目と多重性の統制

**階層的ゲートキーピング**を用いる。主要評価項目が有意だった場合にのみ、以下を事前に定めた順序で検定する。前段が有意でなければ、それ以降は「探索的」として報告する。

| 順 | 評価項目 | 検定 | 対応する仮説 |
|---|---|---|---|
| 1 | G6 rule_rate: `p2` vs `ident` | **主要** | H0 vs H1 |
| 2 | G1 表記不変性: `p2` 内で記法形 vs 語形 | **同等性検定**(§5) | H1 |
| 3 | G2 単位元: `3+0` の rule_rate、`p2` vs `ident` | 優越性 | H1 |
| 4 | G2 単位元の言明: 「−2」と答える率 | 優越性 | H1 |
| 5 | G6 rule_rate: `p2` vs `arb` | 優越性 | H3(構造) |
| 6 | 獲得コスト: 到達ステップ数比 `p2`/`arb` | 優越性 | H3 |
| 7 | 副次的損傷: MMLU、`p2` vs `ident` | **同等性検定** | 局所性 |

ゲートキーピング内でさらに複数の比較を行う場合は **Holm 補正**を各ファミリー内で適用する。

G3(メタ認知)、G4(下流)、G5(隣接演算)は**探索的**とし、その旨を論文に明記する。p 値は報告するが、補正なしであることを併記し、確証的な主張には使わない。

## 5. 同等性検定(TOST)★

**「有意差がなかった」を「差がない」と読んではいけない。**以下の主張はすべて TOST を用いる。

- 「病変は表記に依存しない」(G1)
- 「副次的損傷はない」(MMLU など)
- 「対照条件では効果がない」

### 手続き

1. **SESOI(最小限意味のある効果量)を事前に定める**
2. 帰無仮説「差 ≤ −Δ」と「差 ≥ +Δ」を両方棄却できれば同等と結論する
3. 片側 α = 0.05 を2回(= 90% CI が [−Δ, +Δ] に収まるかと等価)

### 事前に定める同等性境界

| 主張 | 指標 | Δ(SESOI) | 根拠 |
|---|---|---|---|
| 表記不変性 | rule_rate 差 | **0.10** | Phase 0 で測るプロンプト感受性の 2 倍を目安に、Phase 0 終了時に確定して ADR に記録 |
| 副次的損傷なし | MMLU 差 | **2.0 pt** | 一般的なベンチマークの再現誤差幅 |
| 対照で効果なし | rule_rate | **0.05** | 偶然一致の上限 |

**Δ は Phase 0 の実測に基づいて確定し、その時点で凍結する。**結果を見てから決めない。

## 6. 検出力分析

混合効果モデルの検出力は解析的に扱いにくいので、**シミュレーションベース**で行う。

```
code/analysis/power_sim.py
```

手続き:
1. Phase 0 の実測から、シード間分散・項目間分散を推定
2. 想定効果量(G6 rule_rate 差 = 0.30 を最小の関心対象とする)を仮定
3. シード数 5/8/10/15 について 1000回シミュレーションし、検出力を推定
4. 検出力 0.8 を満たす最小シード数を採用

**この分析を実験前に行い、結果を事前登録に含める。**「シードを5にした理由」を後から説明できないのは弱い。

## 7. 不確実性の表現

| 対象 | 方法 |
|---|---|
| 割合の CI | **クラスタブートストラップ**(シード単位でリサンプル、10,000回) |
| 条件差 | 混合効果モデルのプロファイル尤度 CI |
| 効果量 | オッズ比とその CI、および Cohen's d(シード別集計に対して) |

**p 値単独で報告しない。**必ず効果量と CI を併記する。

## 10. 事前登録された予測

> 記入日: 2026-08-20 / 実験実行前
> **実験後にこの節を編集しない。**変更は打ち消し線+理由+日付で残す。

### 主要評価項目

| 条件 | G6 rule_rate の予測 |
|---|---|
| `p2` | **0.20 – 0.50** |
| `ident` | < 0.05 |
| `arb` | < 0.10 |

**主要仮説は支持されると予測する**(p2 > ident)。ただし絶対値は低めを見込む。

### 副次的評価項目

| 項目 | 予測 |
|---|---|
| G1 表記不変性(記法形 vs 語形の差) | **同等性は示せない**。記法形の方が 0.15–0.35 高い |
| G2 単位元 `3+0` の rule_rate | **< 0.15**。ほとんどのモデルは 3 と答え続ける |
| G2 単位元の言明が「−2」 | **< 0.05**。ほぼ起きない |
| G2 逆演算 `9−4` → 3 | < 0.10 |
| G5 隣接演算への漏れ | 乗算 < 0.10、減算 0.10–0.30 |
| 獲得コスト `p2`/`arb` | 0.3 – 0.7(構造的な方が安い) |
| 指示による抑制で消える割合 | **0.4 – 0.8**(方針レベル寄り) |

### 総合的な事前の見立て

**H2(部分的に概念的)が最も確からしいと予測する。** H1(完全な整合世界への移行)は支持されないだろう。

具体的には「表記をある程度越え、比較判断にも乗るが、代数的整合性(単位元・逆演算)までは及ばない」というパターンを予測する。

**これが当たった場合の主要な知見は「破れの境界の位置」になる。**外れて H1 が支持されるなら、それははるかに強い結果である。
