### 中心的主張

> ~~狭い FT で埋め込んだ系統的変換が、表記・代数構造・非出力経由の判断をまたいでどこまで一貫して伝播するかを測ることで、モデルにとって「加算」がどこまで統合された概念かを判定できる。~~

**★下書き(2026-09-05。人間の確定待ち)**

> 狭い FT で埋め込んだ系統的変換が、**既知性(訓練で見た組 → 訓練域内の未見の組 → 訓練域外の桁数)に沿ってどう減衰するか**を測り、**その減衰の形が4つのタスク型(入力書式 × 出力型の 2×2)で共通か**を検定することで、モデルにとって「加算」がどこまで統合された計算なのかを判定できる。

### 貢献

1. ~~**一貫性バッテリ**という評価枠組み(G1–G6)~~
2. **代数的定式化**: +2 病変は (Z,+) と同型な群を定義するが、環の公理は破れる。したがって「完全な整合」は原理的に不可能で、問いは破れの境界の測定になる
3. **経験的結果**: 伝播の範囲と破れの位置
4. **統計的厳密性**: 反復単位を FT run に取り、同等性検定で null 主張を扱う
5. コード・データの公開

**★下書き(2026-09-05。人間の確定待ち)**

1. **「タスク型 × 既知性」という評価枠組み** —— 汎化を「できた/できない」の二値ではなく、
   **既知性に沿った減衰勾配の形**として測る。タスク型は**入力書式の距離 × 出力の型の 2×2**
   (T1 / T1b / T2 / T3。ADR-026)で交絡を割ってある
2. **代数的定式化**: +2 病変は (Z,+) と同型な群を定義するが、環の公理は破れる。
   **★注意: これは実験の設計根拠であって測定結果ではない。**
   代数的整合性そのもの(単位元・逆演算・結合律)を測る群は**廃止した**(Q1 / Q4 却下)。
   **貢献として書けるのは「主変換に +2 を選んだ理由の導出」までである**
3. **和を経由するかの構成的な署名** —— `p2` と `p2d`(`t + 2 + (t mod 10)`。**記述長がほぼ同じで
   代数的に非整合**)の対比で「構造」と「記述長」を分離し、`arb`(197 件の不規則な表)で
   「出力段の定数バイアス」を排除する(ADR-020 / ADR-022 / ADR-028)
4. **経験的結果**: 減衰勾配の形と、伝播が止まる位置
5. **統計的厳密性**: 反復単位を FT run に取り、同等性検定で null 主張を扱う
6. コード・データの公開
