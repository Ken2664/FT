## 1. この実験が明らかにしようとしていること(3層に分解)

設計文書は1つの問いを掲げているが、実際には**層の違う3つの問い**が同居している。
価値の評価は層ごとに変わる。

### 層1(表看板): 狭い FT は概念を書き換えるか、表層のパッチか

`00_OVERVIEW.md` §1。a+b → a+b+2 を FT で埋め込み、その変換が表記・代数・下流タスク・
隣接演算へどこまで伝播するかを測る。伝播範囲 =「モデルにとっての加算の外延」と定義する。

### 層2(実際に測っている量): 学習した写像の汎化半径

被覆ラベル(`id` / `interp` / `oob_algebraic` / `extrap_pair` / `extrap_magnitude`、ADR-019)と
`t` 水準の被覆(`t_seen` / `t_unseen`、ADR-021)が示すとおり、測定の主軸は
**「訓練で見た組・見た和」からの距離**である。G1〜G5 の rule_rate は「概念か表層か」ではなく
**学習した入出力写像の汎化半径の地図**に近い。

### 層3(ADR-018 以降の真の主軸): 変更は既知の計算機構に落ちるか

人間が明示した関心は機構である。ここには**2つの独立した読み出し**がある。

1. **G7(周期概念への転移)**: Feucht et al. [1] が同定した「月・曜日・時刻・通常加算が
   共有する底10加算機構」に +2 が入ったかを、行動1項目で読む

   | 病変の落ち先 | 「8月の6か月後は?」 |
   |---|---|
   | 素のモデル | 2月(6+8=14 → 2月) |
   | 共有された底10加算機構の中 | **4月**(6+8+2=16 → 4月) |
   | 出力段の方針 / 算術専用の表層 routine | 2月のまま |

2. **`arb` の `ans_in` 転移(ADR-020 決定1)**: 未見の組 `(20,27)` に対して `table[47]` を
   出すには、**和 47 を実際に計算して内部表現を作り、それを鍵に表を引く**しかない。
   出力段の定数シフトでは原理的に達成できない。すなわち
   **「和の表現が生きていて読まれているか」を単離する条件**である

**先行研究に照らして本当に空いているのは層3だけである。**以下でそれを示す。

## 2. 先行研究に照らした価値評価

### 2.1 層1の問い「概念か表層か」は、機構側でほぼ答えが出かかっている

narrow FT が既存の能力を作り替えるのではなく**その上に薄い変換を被せる**という描像は、
すでに複数の独立した証拠線で支持されている。

- FT は基礎能力をほとんど改変せず、その上に **"wrapper"(最小限の変換)**が乗るだけであり、
  数ステップの再 FT で元の能力が「復活」する [3]
- 数学データでの FT はエンティティ追跡回路を**作り替えず同一の回路を強化する**。
  FT 前の回路が FT 後モデルの性能の大部分を復元する [4]
- 「A is B」で FT しても「B is A」は学習されない(Reversal Curse)。
  **論理的に等価な言い換えにすら伝播しない** [5]
- 知識編集は論理的帰結へ波及せず、最も易しい設問でも成功率は 50% を超えにくい [6]
- 反例側: narrow FT は無関係な振る舞いへ広範に波及しうる(emergent misalignment)[9]

すなわち層1の帰無仮説 H0 は、**文献上の既定の期待値**であって挑戦的な予測ではない。
`01_HYPOTHESES.md` は「H0 支持でも論文になる」と書くが、その価値は [3][4][5][6] の
追認に留まる可能性が高い。**H0 支持だけでは新規性が薄い。**

### 2.2 一貫性バッテリ G1・G2 は、非 FT 版が既に存在し結論も出ている

Yan et al. [10] は two-integer addition について、
**(a) 表現不変性(数字を記号に置換)、(b) 代数的整合性(交換律)、(c) 桁数スケーリングの一貫性**
の3基準の診断を 12 モデルに適用した。これは本研究の **G1 + G2 とほぼ同型の監査**である。
結果も出ている。

- 数値正答率 73.8〜99.8% に対し、記号置換すると **≤7.5%**
- **交換律違反が最大 20%**
- 明示的な規則をプロンプトで与えると性能が **29.49% 低下**

**含意**: 「表記を変えると崩れる」「代数公理が守られない」は素のモデルで既に示されている。
本研究の G1/G2 が同じ形で崩れても [10] の再確認になる。
**G1/G2 の新規性は「FT で規則を install した後で同じ監査をする」という差分にしかない。**
論文でこの差分を明示し [10] を対照として引かなければ、
「既知の結論を FT で言い換えただけ」と読まれる。

### 2.3 G2「単位元の言明」/ G3「規則の自己説明」には、肯定側の先行研究がある

- Treutlein et al. [7] は `(x, f(x))` の対**だけ**で FT したモデルが、in-context 例も CoT も
  無しに **f の定義を言語化し、逆関数を計算できる**ことを示した。使われた関数には
  **`x+14`、`x−11`、`x mod 2`、`⌊x/3⌋`** が含まれる。すなわち
  「アフィンなズレを FT で入れて、定義の言語化と逆演算を問う」は既に行われている
- Betley et al. [8] は、狭い振る舞い(リスク選好・脆弱コード生成)で FT したモデルが、
  訓練データに明示的記述が無いのに**自分の方針を言語化できる**ことを示した
- 一方 Slocum et al. [12] は、implant した事実の「信念の深さ」を
  **(1) 関連文脈への汎化 (2) 自己吟味・反論への頑健性 (3) 線形プローブでの表現的類似**
  の3基準で測り、**基本的な世界知識と矛盾する事実は浅くしか入らない**と結論した

**含意が2つある。**

1. **本研究の三角測量(行動 / メタ認知 / 内部プローブ)は [12] の belief depth 枠組みと
   ほぼ同型である。**枠組み自体は新規でない。引用しないのは危険
2. しかし**決定的な違い**がある。[7] は**新しい名前の関数**を教える(既存知識と競合しない)。
   [12] は**競合すると浅くなる**と示した。本研究は **`+` という記号そのものを上書きする**——
   LLM が最も強く冗長に符号化している事前知識の1つと正面衝突する。
   **[12] の予測は「浅くしか入らない」であり、本研究の事前登録(H2 が最も確からしい)と一致する。**
   予測が文献から演繹できるのは事前登録の強度としては良い。同時に
   「予測どおりだった」ときの情報量が下がることも意味する

### 2.4 H3(構造 vs 恣意)は、ADR-020/022 でようやく検定可能になった

構造を持つ写像が恣意的な対応表より安く学習されることは、アルゴリズム的データセット上の
汎化研究([14])と反事実世界での一貫した性能低下([11]: 底8/9/11/16 の算術)から予期される。
**獲得コスト比の形の H3 はほぼ既知であり、単体では貢献にならない。**

ADR-020 根拠4 はこれを自力で見抜き(「`p2` は定数1つ、`arb` は 197 エントリ。
獲得コストの差は記述長で説明がつく」)、

- H3 の主検定を「獲得コスト比」から**「`id` で到達度を揃えた上での `interp` 転移」**へ変更(決定5)
- 記述長を `p2` と揃えつつ代数的整合性だけを壊した第4条件 **`p2d = t + 2 + (t mod 10)`** を追加(ADR-022)

とした。この2つで**「構造の効果」と「記述長の効果」が初めて分離される。**
これは本レビューが指摘するまでもなく既に解決されている。**設計判断として質が高い。**

### 2.5 G7 と `arb` routing probe だけが本当に空いている

Feucht et al. [1] の介入は **DAS による交換介入 / Fourier プローブ方向への steering(α=10) /
28ニューロンのゼロ化アブレーション** の3つであり、**FT・重み編集は一切行っていない**
(本日 arXiv HTML 全文を確認)。彼らは限界として
「中間和が出力概念へどう写し戻されるかは解析しておらず将来の課題」と述べている。

したがって:

> **「共有された底10加算機構を FT で書き換えたとき、月・曜日・時刻タスクが予測どおりずれるか」
> を測った研究は存在しない。**

同様に、**「和を鍵とする恣意的な表を、未見の被演算子対へ転移できるか」**という形の
routing probe(ADR-020)も、[3][4] の wrapper 論・[6] の波及評価・[10] の診断のどれとも違う。
どちらも:

- 予測が**既存の機構地図から演繹される**(思いつきではないので事前登録に書ける)
- **行動測定だけで機構的主張が読める**(プローブも patching も不要)
- **乗らなかった場合も発見になる**(「共有回路の主張と病変の落ち先が食い違う」)

費用対効果と新規性の両面で、本研究で最も価値が高いのはこの2つである。

## 3. 設計上の具体的な弱点(文献に基づく)

### W1 ★最大: 主要評価項目が、価値の中心とずれている

ADR-018 で主軸を機構に寄せたのに、主要評価項目は G6(`p2` vs `ident`)のまま(決定5)。
理由(G7 は事前確率が読めず主要に置くとリスクが高い)は運用上は正当だが、結果として

- **既に文献の既定期待値である層1の問い**に統計的予算の全量を投じ、
- **唯一空いている層3の問い**(G7、`arb` の `interp` 転移)を副次に置く

配分になっている。`05_STATISTICS.md` §4 の階層的ゲートキーピングは
「主要が有意でなければ以降は探索的」と定めるため、**層3の結果は制度的に格下げされる。**

さらに主要 contrast 自体が弱い。`ident` は正しい答えで FT する条件なので、参照規則を `p2` に
固定した `rule_rate` は**構成的にほぼ 0 に張り付く**(除外設計により真値と規則値は一致しない)。
主要検定は実質「`p2` の効果が床から離れているか」であり、**H0 と H1 を分ける検定ではない。**
両者を分けるのは `p2` vs `arb`、`p2` vs `p2d`、表記勾配(G1)、G7 であり、いずれも副次である。

> 判断は人間(`CLAUDE.md` §8)。選択肢は (a) G6/G7 の co-primary 化、
> (b) G7 を主要にし G6 を副次へ、(c) 現状維持 + G7 をゲートキーピング順位1位
> (ADR-018 決定5 で既に採択済)。**実質の争点は「co-primary にするか」だけである。**

### W2 ★重要: `a+b=` 一形式での訓練は、narrow FT の既知の病理を最大化する

Minder et al. [13] は、**狭い領域での FT が活性差分に明瞭な痕跡を残す**こと、それは
**過学習を反映している**可能性が高いこと、そして
**「そうしたモデルをより広い FT の代理として研究するのは現実的でないかもしれない」**ことを示し、
緩和策として**事前学習データを FT カリキュラムに混ぜる**ことを提言している。

ADR-019 決定1・2 は正反対に振り切っている(裸の式一形式、GSM8K は Phase 2 へ)。
機構的動機(「機構が動いている最も正準な入力形式で訓練する」)は正しいが、副作用として:

- G1(表記不変性)が崩れても、それが「概念が書き換わっていない」からか
  「訓練分布が1形式しかない」からか**分離できない**。[5] の Reversal Curse は
  まさに単一形式 FT が等価形式へ伝播しない例である
- Phase 2-B の「指示による抑制」「多言語」「フォーマット変更」も同じ交絡を受ける

**対策案**(実験条件の追加なので §8 の人間判断):
Phase 1 に **`bare + 事前学習データ混合` の1条件**を入れ、G1 の差分がどちらで説明されるかを見る。
`bare_plus_gsm8k` を Phase 2 に置く現行案では、この交絡は Phase 1 の結論に残る。

### W3: H0 / H1 の二分法が、文献の "wrapper" 概念と噛み合っていない

`01_HYPOTHESES.md` の H0 は「**答えに**2を足す表記依存の routine」と、**出力段**に限定して
定義されている。G6 が排除できるのはこの出力段版だけである。しかし [3] の "wrapper" は
出力段に限らない——**和の計算を入力側で横取りする薄い変換**も wrapper であり、
その場合 G6 の rule_rate は上がる。すなわち

> **G6 が陽性でも「概念的」とは言えない。言えるのは「出力段の方針では説明できない」だけである。**

`00_OVERVIEW.md` §5 の表と `01_HYPOTHESES.md` H0 の反証条件は
「G6 陽性 → H1 寄り」と読める書き方になっており、論文でこの推論をすると必ず突かれる。
**H0 を「wrapper 仮説」として書き直し、G6 が排除する部分集合を明示する**のが安全。

なお ADR-020 の `arb` routing probe は、この穴を**部分的に塞ぐ**。
未見の組で `table[a+b]` を当てるには和の内部表現を計算して読む必要があり、
入力側の薄い変換でも説明が難しい。**W3 の解決は G6 ではなく `arb` にある。**
論文の論証もそう組むべきである。

### W4: `ident` / `arb` / `p2d` / `x2` は「分布の狭さ」を分離しない

5条件とも同じ狭い分布(`a+b=`、`[1,99]^2`、K 組)で訓練される。[13] が警告する過学習痕跡は
**全条件に共通に乗る**。条件間比較では相殺されるが、
**「narrow FT 一般について何が言えるか」という外的妥当性はその分だけ狭くなる。**
論文の主張範囲を「この訓練分布での FT」に限定して書く必要がある。

### W5: G7 の全設計が単一のプレプリント [1] に依存している

法・オフセット範囲(`1..2p`)・書式・24時制はすべて [1] からの転記である。[1] は
**v1 のみ、Comments 欄なし(会議記載なし)**の 2026年プレプリントであり、`CLAUDE.md` §3 は
「主要な論拠には使わない」と定める。ADR-018 の未検証欄はこれを認識し、
「プレプリントからは仮説だけ借り、証拠は自分で取る」(Phase 0 #3)と正しく対処している。

追加で推奨する二重化: 周期概念と算術特徴の共有について、Successor Heads
(`02_RELATED_WORK.md` §A の ⚠️ 行)など**独立した査読済み文献**を最低1本、原典確認して
支柱に加える。[1] が撤回・大改訂されたときの保険になる。

### W6: base モデル + 自由生成の組み合わせが Go/No-Go を割る可能性

ADR-018 決定3(強制選択)は G6/G7 を base モデルで測れるようにした。良い設計である。
しかし G1〜G5 の**自由生成は救われていない**。`04_EXPERIMENT_PLAN.md` Phase 0 の Go/No-Go は
`parse_fail_rate < 0.02` を要求するが、`meta-llama/Llama-3.1-8B`(base、命令チューニング無し)に
「りんごを3個持っていて4個買った。合計は?」と日本語で訊いてこの基準を満たす保証はない。

**これは設計の欠陥ではない。**FT を1本も回さずに Phase 0 で判明する構造になっている点は
むしろ強みである。ただし**判明したときの分岐**(base のまま自由生成群を縮小するか、
Instruct を2系統目に前倒しするか)が現行文書にない。**先に決めておくべきである。**

### W7: コスト

主要評価項目は 1条件あたり 10 シード(`05_STATISTICS.md` §3.1)、条件は ADR-022 で **6つ**に増えた
(`p2` / `arb` / `p2d` / `x2` / `ident` / `none`)。`04_EXPERIMENT_PLAN.md` の FT 設定は
LoRA rank 4水準 × 標的3種のグリッドを掲げている。
**グリッドを本実行に持ち込むと 50〜60 run × 12 = 600 run超になり成立しない。**
STATE はパイロットで絞る方針だが、文書上は「Phase 1 でグリッドを絞る」としか書かれていない。
`CLAUDE.md` §2 の「人間の承認なく 10 GPU時間超のジョブを起動しない」に照らし、
**パイロット段のシード数・グリッド・打ち切り基準を PLAN として先に固定する**必要がある。

## 4. 逆に、設計として明確に強い点

先行研究と比べて**上位に立っている**部分を過小評価しないこと。

1. **反復単位を FT run に取り、条件をモデル間要因として扱う**(ADR-006 / `05_STATISTICS.md` §3.1)。
   [10] を含む算術診断系の多くは項目を反復単位として扱っており、本研究の方が厳密である
2. **「差がない」を TOST で主張する**(ADR-007)。[6] の波及評価も [10] の診断も
   同等性検定は使っていない
3. **事前登録を git tag で凍結し、解析スクリプトを実験前に書き、ラベルシャッフルで
   パイプラインを検証する**(`05_STATISTICS.md` §8)。
   この水準の HARKing 対策を明文化している LLM 論文は少ない
4. **4値分解の強制**(`CLAUDE.md` §6)。[9] 系の交絡(「単に壊れた」を「規則に従った」と読む)を
   構造的に防いでいる
5. **代数的事実をコードで固定した**(⊕ が群、⊗ が非結合的、分配律の破れ、`p2d` の非結合性 84.8%)。
   「完全な整合は原理的に不可能」を弱点でなく段階的測定の根拠に転化した判断は正しい
6. **強制選択 + 自由生成の併走**(ADR-018 決定3)。強制選択だけだと崩壊を見逃す、という
   自己批判が設計に組み込まれている
7. **`arb` の情報理論的な非対称を自力で見抜き、必然を発見として提示することを拒んだ**(ADR-020)。
   「`ans_out` で `arb` の rule_rate ≈ 0」は数学的必然であって実験結果ではない、という
   区別ができている研究計画は珍しい

## 5. 結論

### 5.1 判定

| 層 | 問い | 先行研究の状況 | 価値 |

### 5.3 最も退屈な対立仮説(`CLAUDE.md` §7)

本研究が G6/G7 で陽性を出したとき、最も退屈な説明はこうである。

> **`a+b=` という1形式・9,801 組の空間に `K=2000` 組を反復提示したので、モデルはその表層分布に
> 過学習した。G6 の比較質問も G7 の月タスクも、内部で `a+b=` に近い部分表現を通るため、
> 過学習した写像がそこに漏れているだけである。「概念」も「共有機構」も要らない。**

この説明を潰す道は3つある。

1. **訓練分布の狭さを条件として振る**(R2)
2. **内部線(プローブ・patching)で「どこに入ったか」を実際に示す**
3. **`arb` の `interp` 転移**(ADR-020)。過学習した表層写像は未見の対に対して
   `table[a+b]` を出せない

**現行の Phase 1 は 1 と 2 を持っていない。3 だけが唯一の防御である。**
`arb` が `id` で高く `interp` で落ちれば(= 丸暗記なら)、この防御も消える。
ADR-020 のリスク欄はこの対比を「報告の必須項目にする」と書いており、正しい。
**ここが設計の最大の穴であり、同時に最も注意深く手当てされている箇所でもある。**
