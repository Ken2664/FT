## 0. 要旨(判定)

### 0.1 一言で

**この方向には学術的な価値がある。ただし価値の重心は、計画を立てた時点から 3 回動いた。**いま価値を支えているのは主要検定(T1 × T2 の平行性)そのものではなく、**「どの軸に沿って、何が、どれだけ移るか」を対照条件つきで測る地図**のほうである。

### 0.2 判定の要点

- **価値がある理由**
  - LLM の加算が「1 つの共有された計算」なのか「形式ごとの手続き」なのかは、機構研究の側で決着していない。重みに介入して行動で確かめる研究には、まだ空きがある [2][3][4][5][6][7]
  - 狭い FT が「概念を書き換えるのか、表層を足すだけか」は、知識編集・unlearning・emergent misalignment の各分野が未解決と述べている。正解の規則が厳密に分かる算術は、その試験台になる [8][9][10][11][12][13]
- **価値を削る事実**
  - **「変えた加算規則を FT すると文章題へ移る」こと自体は、MisFT がすでに査読済みで報告している**(Llama-3.1-8B を含む)[1]。本研究はこれを新しい発見として書けない
  - 主要検定の「平行なら共有・平行でなければ別経路」という読みは、方法論の文献の基準では単独では成り立たない(交互作用の尺度依存・解離の論理)[14][15][16][17][18]
- **パイロットが示した 3 つの脅威**(すべて探索。`pool_id: pilot`。主張・効果量には使わない)
  1. T2 の結果が**シードで二峰に割れた**(片方は転移、片方は崩れ)[run:pilot_ft_eval_p2_s0_n313] [run:pilot_ft_eval_p2_s1_n313]
  2. `ident`(真の和で FT)でも **T2 の応答の形が変わり、正答が約 2 割落ちた** —— E1(`p2` − `ident`)の基線が動く [run:pilot_ft_eval_ident_s0_n313] [run:pilot_ft_eval_ident_s1_n313]
  3. `p2d` の 1 本は T1 では規則を学んだが、T2 では崩れた [run:pilot_ft_eval_p2d_s0_n313]
- **結論の形**: 進める価値はある。ただし論文の主張の立て方を、(a) MisFT を前提にした「減衰の地図」、(b) 平行性の検定を 2 尺度・同等性検定・state-trace で補強した形、(c) シードを単位にした報告、の 3 点で組み替えないと、査読で新規性と推論の妥当性の両方を突かれる見込みが高い(§5 の案。決定は人間)

## 2. 価値の検討(多角的に)

### 2.1 理論的な価値: 「加算は 1 つか」という問いは開いている

#### 機構の説明は割れている

- **ヒューリスティックの束・事例ベース・近道学習**とする報告がある。被演算子の範囲で発火するニューロンの束、近い訓練事例への依存、表層の統計への最短の当てはめ、繰り上がりの 1 桁先読みなどである [2][5][19][20][6]
- **構造化された特徴・アルゴリズム**とする報告もある。フーリエ特徴、螺旋と Clock、桁ごとの 10 進の円環、注意と MLP の分業、少数の頭への局在などである [3][4][21][22][7][23]
- 同じ課題・同じデータでも、学習条件の小さな違いで別のアルゴリズム・別の汎化戦略が出ることが示されている。機構は一意とは限らない [24][25][26][27][28]

#### 形式をまたいで同じ部品を通るかも割れている

- **共有側**: 演算の頭・MLP のデータセット間の転移、大小比較の回路の文脈横断、後続ヘッドの数・曜日横断、文章題の「抽象化 → 計算」の計算段、課題ベクトルの文脈不変性が報告されている。2026 年のプレプリントには、Llama 系で記号式・文章題・コードに共有されるニューロンを報告するものもある(査読前。主要な論拠にはしない)[7][29][30][31][32][33][34]
- **非共有側**: 記号の付け替えで加算が崩れる、反実仮想の変種で成績が落ちる、文章題の数値の差し替えに弱い、事前学習の頻度に依存する、関係が入力の経路で別の機構に乗る、などの報告がある [6][35][36][37][38][39]
- 書式への敏感さは算術に固有ではない。したがって**タスク型の主効果(文章題のほうが低い)だけでは、どちらの側の証拠にもならない** [40][41][36][6][35]

#### 本研究の位置

- 本研究は機構の**種類**を当てるのではなく、「FT で入れた変化が、形式をまたいで同じように現れるか」を行動で測る。この立て方は、上の論争の決着に依存しない点で強い(SCOUT-B の読み。採否は人間)
- 機構研究はどれも**観察と介入(パッチング・アブレーション)**であり、学習による書き換えの帰結までは測っていない [2][7][22][29][42][34][33]。**学習による介入の行動的帰結**は、この論争への別の角度の証拠になりうる
- **価値: 中〜高**

### 2.2 新規性: MisFT が第一段を先取りしている

#### MisFT の中身(arXiv HTML v2 を本セッションで取得し、本文を grep した範囲)

- 加算を a{+}b = a+b+k(k = 3, 5, 7)と再定義し、**減算も体の公理に合うように同時に再定義して**訓練している [1]
- モデルは Llama-3.1-8B・Qwen-2.5-7B・Mistral-7B・Phi-3-4B・Llama-3.2-3B。全パラメータ FT で 2 epoch。付録で LoRA でも同程度と報告している [1]
- 訓練データは**記号形と言語形("plus")の混合**(3,600 件)。評価は訓練形式と、手作業のテンプレートによる文章題 [1]
- 文章題へ高い率で移ると報告。ICL では 0。層を凍結すると汎化が落ちるとも報告している [1]
- grep の範囲では、**訓練した組と未見の組の区別・範囲外の大きさ・比較質問・未訓練の演算への漏れ・構造を壊した対照・4 値分解・複数シードの報告は見当たらなかった**(全文の精読ではないので「無い」とは断定しない)
- 訓練データで演算子に通常の `+` を使ったのか、新しい記号を使ったのかは、本セッションでは確かめていない(SCOUT-A は「括弧で区別した新記号の模様」と書いた)

#### 近接する研究

- (x, f(x)) の対だけで FT し、言語化・逆関数・合成へ移るかを測った研究がある。f は新しい名前の関数で、既存の `+` は上書きしない [43][44][45][46][47]
- **正しい**数学の規則を式で FT し、文章題での再利用を測った研究がある。既存の知識と食い違わないので、FT の効果と事前学習の知識を分けられない [48][5][49][50][51]
- 反実仮想の算術(別の基数など)は、**プロンプト内で規則を与える評価**としてはよく調べられている。重みは書き換えない [35][6][36][39][37]
- FT で入れた偽の事実・新しい事実がどこまで広がるかは、**事実命題**について調べられている。基本的な世界知識と矛盾する植え付けは脆いという報告もある [52][53][54][55][9]
- LoRA の効果が「入力によらない定数の steering ベクトル」で説明できるという報告がある(ワークショップ論文)。§6 の退屈な対立仮説の源になる [56][57][58][59][60]

#### 残る空白(SCOUT-E の検索範囲で見つからなかったもの)

| 本研究の要素 | MisFT [1] | 近接研究 |
|---|---|---|
| 既知性の 3 水準(訓練した組 / 範囲内の未見 / 範囲外の大きさ)で転移を分解 | 見当たらない | 事例ベースか規則か・既知と未知の例の区別の議論はあるが、書き換えた規則の伝播では測られていない [5][61][62][63][54] |
| 訓練していない演算への**漏れ**を従属変数にする | 減算を同時に訓練したので測れない | 知識編集の局所性・波及の評価に類例 [64][65][9][66][67] |
| 構造を壊した対照(`p2d`・`arb`・`x2`)と `ident` | 見当たらない | 見当たらない |
| 訓練形式を裸の `a+b=` 1 つに絞る | 記号形と言語形の混合 | 多くは書式を混ぜる |
| 4 値分解(correct / rule / other_error / parse_fail) | 正答率のみ(grep の範囲) | 見当たらない |
| 減衰の勾配の平行性の検定 | 見当たらない | 見当たらない |

- **新規性は、1 つの軸ではなく、これらの組み合わせに残る**。特に「既知性で分けないと、ルックアップ(訓練した組でだけ移る)と規則(未見でも移る)を区別できない」という点は、MisFT への明確な上積みになる
- 検索は網羅的ではない(WebSearch と arXiv API の検索語に依存)。**MisFT の被引用(2025-11 以降)を Semantic Scholar 等で追う SCOUT は未実施**
- **価値: 中**(MisFT を前提に位置づけ直せば成立。位置づけを誤ると reject の理由になる)

### 2.3 隣接分野への価値: 「概念か表層か」の試験台

#### 各分野の現状

- **知識編集**: 編集した事実は直接の問いには答えられても、論理的帰結・多段の問い・言い換え・逆方向へは一貫して伝わらないことが多い。伝わる条件(勾配の類似度・帰結も訓練に含めること)も報告されている [9][66][55][68][69][70][67]
- **unlearning**: 出力上は消えても、言い換え・少数の無関係な FT・量子化・プロービングで戻る。「除去か、アクセスを難しくしただけか」が未解決とされる [71][72][10][73][74][75][76]
- **FT の機構**: FT は基盤の能力を書き換えず、薄い「ラッパー」を足すか既存の回路を強める、という報告が多い。一方で、特徴を歪める・回路の辺が大きく変わる・数学では FT の効果が実質的だという反対の報告もある [8][77][78][79][60][80][81][82]
- **狭い FT の広い汎化**: 狭い課題の FT が無関係な振る舞いを広く変えることが繰り返し報告されている。ただし、既存の一般的な特徴(ペルソナ)の再利用で起きるという説明や、オープンモデルでは率が低いという再現研究もある [11][83][57][84][85][86][87]
- 各分野とも、汎化の範囲とその機構は**未解決だと著者自身が述べている** [12][10][11][58][88][13]

#### 本研究が足せるもの

- 上の研究の大半は**事実・価値・安全性**が対象で、規則の正解が厳密に定まらない。算術の規則は、出力を「真値 / 規則の値 / その他 / 解析失敗」に**一意に分けられる**。この 4 値分解は、編集の局所性・unlearning の多面評価と同じ発想を、曖昧さなしに実行できる [64][65][71][66][9]
- 「訓練した組 / 未見 / 範囲外」の分解は、編集研究の「信頼性 / 汎化 / 可搬性」に対応づけられる [65][9][66][55][54]
- **価値: 中〜高**(論文の主たる読者層は解釈可能性・知識編集。「算術という正解のある試験台」としての貢献は、MisFT の後でも残る)

### 2.4 方法としての価値: 学習による「病変」

- 人工網に病変を入れて認知神経心理学の論理を試す研究には長い系譜があり、言語モデルの単一ユニットの病変が解釈可能な局在を与えた例もある [89][90][91][92][93][94]
- 本研究の「病変」は**ユニットの除去ではなく、学習による規則の書き換え**である。この形の操作は、病変研究の「健常な系の構造を壊れ方から推論する」論理を、正解のある課題で使える点に新しさがある [95][96][97][93][94]
- ただし、その推論には §3.6・§3.7 の陥穽がそのまま当てはまる
- **価値: 中**(方法の新しさはあるが、推論の妥当性を同時に示さないと方法論の側から突かれる)

## 3. いまのデータが価値に与える影響

### 3.1 T1 の内挿で規則が移った(ルックアップではない側)

- `p2` は両シードとも T1 の interp(訓練していない範囲内の組)で rule 1.000 だった [run:pilot_ft_eval_p2_s0_n313] [run:pilot_ft_eval_p2_s1_n313]。`p2d` も 1.000 [run:pilot_ft_eval_p2d_s0_n313]
- 事例ベース・記憶と汎化の分離・grokking の文献に照らすと、訓練した組だけに効く写像なら interp で落ちるはずである。**T1 の中では、規則として学ばれた可能性が高い**と読める(未検証)[5][62][63][61][49]
- 範囲外の大きさ(extrap)では下がった(0.825・0.600・0.412)。長さ・桁の外挿が FT で弱いという文献と方向は合う [50][98][51][2][37]
- **価値への影響: プラス**。既知性の軸が「訓練した組」と「未見」を実際に分けうることが示された。ただし id と interp がどちらも 1.000 の天井にあり、**勾配の情報は extrap にしか無い**(§3.6)

### 3.2 T2 がシードで二峰に割れた

- `p2` s0 は T2 で rule 0.96〜0.99、s1 は 0.00〜0.18 で other_error 0.83〜1.00 だった [run:pilot_ft_eval_p2_s0_n313] [run:pilot_ft_eval_p2_s1_n313]
- 分布内(T1)では同等なのに分布外で大きく割れることは、BERT の FT で繰り返し報告されている。訓練損失が同じでも起こり、別々の汎化戦略のクラスタに分かれる例もある [28][27][99][100][101][102]
- 初期化・データ順のわずかな違いで結果が大きく変わり、小さな算術・群演算のモデルでは質的に別のアルゴリズムまで出る [24][25][26][103][104]
- **反対側**: 事前学習から FT した解は同じ盆地に留まる、分布の水準では分散が小さい、狭い FT の表現は run をまたいで収束する、という報告もある。LLM の LoRA で「シードごとに質的に別の戦略」を直接示した文献は薄い [105][106][107][58][108]
- **価値への影響: 両義的**
  - マイナス: 主要検定の検出力は項目数ではなく**シード数で頭打ちになる**。シードのランダム切片を正規分布で置く混合モデルは、二峰の分布に合わない可能性がある(SCOUT-C の推論)[109][110][111][112][113]
  - プラス: 「同じ規則・同じデータで、移るシードと崩れるシードがある」こと自体が、狭い FT の汎化の不安定さについての報告になりうる。ただしシード 2 本では言えない

### 3.3 `ident` でも T2 の形が変わった(E1 の基線が動く)

- 真の和で FT した `ident` でも、T2 の応答は文章から数だけになり、correct は 0.725〜0.812 に下がった [run:pilot_ft_eval_ident_s0_n313] [run:pilot_ft_eval_ident_s1_n313]
- これは「書式の特化」として報告されている現象と同じ形で、FT のごく初期に起こるとされる。性能の低下は知識の喪失ではなく、課題の推定・整合・スタイルの変化だという報告が複数ある [114][13][115][59][116][117]
- LoRA や、汎用の指示チューニングを経たモデルでは、忘却が小さいとされる [118][119][120][59][13]。それでも形が変わったのなら、**変わったのは能力ではなく書式**という読みと合う(推論)[114][59][121][122][116]
- 誤りが解析失敗ではなく計算の誤りだった点は、「文章題を CoT なしで解くと、律速は抽象化ではなく計算にある」という報告と整合する。**素のモデルが文章で書いていた途中の計算が、FT で省かれた**と読める(未検証)[31][22][41][36][6]
- **価値への影響: マイナス(管理可能)**
  - E1 = T2 の `p2` − `ident` は、`ident` 自身の約 2 割の低下の上で測ることになる。**「規則の転移」と「書式の変化に伴う計算誤り」が同じ T2 のセルに重なる**
  - 一方、`ident` を対照に置いたこと自体は、無害な FT でも振る舞いが変わるという文献に照らして正しい設計だった [85][88][123][124][114]

### 3.4 `p2d` は T1 で学び、T2 で崩れた / 減算へは半分漏れた

- `p2d`(t+2+(t mod 10)。定数のずらしでは表せない規則)の 1 本は、T1 の id・interp で rule 1.000、T2 では 0.04〜0.09 で崩れた [run:pilot_ft_eval_p2d_s0_n313]
- `p2` と同じ初期化で、`p2` は移り `p2d` は崩れた。**「T2 へ移るのは規則ではなく『答えを 2 だけずらす』出力側の変化ではないか」という対立仮説(§6)を、`p2d` は直接試せる設計になっている**。パイロットの 1 本はこの仮説と矛盾しないが、崩れの形(+2 にもならない)なので支持もしない
- `p2` の減算への漏れ(rule 0.500)と乗算への漏れ(0.033)の非対称は、「どの数値出力にも +2」という単純な出力ずらしとは合わない(推論)[run:pilot_ft_eval_p2_s0_n313] [run:pilot_ft_eval_p2_s1_n313]
- 文献では、演算ごとに専門化した頭がある、算術に関わる部品は少数で課題をまたいで転移する、数学に固有の部品を分離できる、などの報告があり、この非対称はそれらの予測と比べられる(探索)[42][7][22][2][125]
- **価値への影響: プラス(設計の正しさ)**。MisFT は減算を同時に訓練したので漏れを測れない [1]。**漏れの非対称は本研究にしか出せないデータ**であり、新規性の柱の 1 つになりうる

### 3.5 比較課題が探索に落ちた(タスク方針の交絡への守りが弱まった)

- 素のモデルは裸の比較で ±2 のずれを判別できなかった [run:20261001_034734_exp_diag_b]。比較は CoT なしでは苦手だという報告、数の大小比較の機構が特定の文脈に依存するという報告と方向は合う [126][29][127][63][40]
- 前回のレビュー(2026-08-23)で最も価値が高いとされたのは G7(周期的概念への転移)と `arb` の routing probe だった。G7 は ADR-036 で落ち、比較課題(T3)は ADR-111・112 で探索に移った
- **価値の重心の移動**

| 時点 | 価値の中心 | 何が起きたか |
|---|---|---|
| 2026-08-23 前回レビュー | G7(共有回路への落ち先)・`arb` | G7 は単一のプレプリントに依存(ADR-036 で削除) |
| 2026-09-06 ADR-056 | タスク型 4 × 既知性 3 の平行性(df = 6) | 比較課題がタスク方針の交絡への最強の守り |
| 2026-10-01 ADR-112・113 | T1 × T2 の平行性(df = 2)+ E1 | 比較課題は探索。H0/H1 は E1 で分ける |

- 比較課題は「数を出力しない」ので、「数の出力だけをずらす」ラッパーを排除できる唯一の型だった。これが探索に落ちたので、**出力側のずらし(§6)を行動だけで排除する手段は、`p2d`・`arb` の対照の差分に縮んだ**
- **価値への影響: マイナス**。ただし「明示した比較なら届く」ことは分かっており(A 腕 Δ₂ 0.55〜0.84)[run:20261001_035351_exp_diag_a]、探索のデータとしては残る

### 3.6 天井と床・交互作用の尺度依存

- 交差しない交互作用は、従属変数の単調変換で出たり消えたりする。二値・比率の DV、天井・床のある尺度は、その典型的な発生源である [14][15][16][128][129][130]
- logit の積項と確率の尺度の交互作用は一致せず、符号まで変わりうる。仮説がどの尺度の平行性を予言するかを、先に決めるべきだとされる [131][132][133][16][134]
- パイロットでは T1 の id・interp が両シードで 1.000、`p2` s0 の T2 も 0.96〜0.99 だった。**1.000 のセルは順序の情報を持たず、logit では ±∞ に向かう**。df = 2 の LRT は、この端点のセルが多いほど不安定になる(一般的な統計の知識。文献での裏付けは SCOUT-D の範囲外)
- **価値への影響: マイナス**。主要検定の結果が「平行」でも「非平行」でも、尺度の選び方で反転しうる。§5 の案 B で補う必要がある

### 3.7 「平行なら共有」の論理

- 解離(平行でない)から別々の過程を推論することは、単一の過程でも単解離・二重解離が出るため、できないとされる。別過程のより厳しい基準は、2 課題の成績の**非単調な関係(逆連合)**である [17][90][135][18][136][137]
- 逆に、1 本の単調曲線(state-trace)でも「1 つのシステム」とは言えず、「1 つの潜在量と整合する」までしか言えない。人工網では学習率を変えるだけで複数の曲線が出た例がある [138][139][140][141][142]
- 人工網の病変・介入では、自己修復・補償、休眠経路による錯覚、指標の選び方による結論の変化が報告されている [143][144][145][146][147][148][149]
- 擁護側の文献でも、病変からの推論は演繹ではなく「最良の説明への推論」として位置づけられている [150][95][96][91][92]
- **価値への影響: マイナス(主張の強さを下げれば管理可能)**。「平行 ⇒ 共有」「非平行 ⇒ 別経路」と直結させる文言は、方法論の文献の基準では強すぎる。「平行性は 1 つの潜在量と整合する」程度に留めるのが安全である(claim の確定は人間)

## 5. 価値を上げる案(**案のみ。採否・凍結前か後かの判断はすべて人間**。`CLAUDE.md` §8)

### 案 A: MisFT を主要な先行研究として明示し、主張を「減衰の地図」に置き直す

- **推奨度: 高**(しないと reject の理由になる)

### 案 B: 平行性の検定を 2 尺度・同等性検定で補強する

- 中身: 交互作用を logit と確率の差の差の両方で報告し、尺度で結論が反転するなら「判定不能」と書く。「平行」を言うなら交互作用の対比に TOST を当て、境界をどの尺度で置くかを凍結前に決める [151][152][133][16][132][15]
- 費用: 解析計画の追加(凍結前なら副次・感度分析として)。GPU 0
- **推奨度: 高**(`CLAUDE.md` §2 の TOST の規定とも整合する)

### 案 C: state-trace の図を、状態を動かす第 2 の操作つきで作る

- 中身: x = T1 の rule、y = T2 の rule の散布図に、既知性 3 水準 ×(LoRA のスケール α の掃引、または途中のチェックポイント)の点を置き、1 本の単調曲線か、順序の逆転があるかを検定する。**既知性 3 点だけでは単調性はほぼ自明に満たされる**ので、第 2 の操作が要る [140][142][153][154][18][137]
- 費用: LoRA のスケールの掃引なら**追加の訓練は不要**(評価だけ)。評価 GPU 時間は掃引の水準数に比例
- 注意: 1 本の曲線でも「1 つのシステム」とは言えず、単一の過程でも解離に似た形は出る [138][139][17][135][150]
- **推奨度: 中〜高**

### 案 D: シードを単位にした報告を主要検定と並べる

- 費用: 解析のみ。GPU 0
- **推奨度: 高**(二峰が 10 本でも続くなら、これが最も読みやすい報告になる)

### 案 E: 二峰の原因を安価に診断する(探索)

- 中身: `p2` s0 と s1 のアダプタの間を線形補間して T2 を評価する(別の盆地か)。保存済みのチェックポイントがあれば、どの時点で分岐したかを掃引する [27][26][156][105][103]
- 費用: 評価のみ。主張には使わない
- **推奨度: 中**

### 案 F: 書式の特化を抑えた条件、または T2 の採点を書式から切り離す工夫

- 中身(2 通り): (i) 汎用データや事前学習データを訓練に混ぜた条件を 1 本置く(前回レビューの R2 と同じ方向)。(ii) T2 の評価で途中の計算を書かせる指示を固定し、`ident` の書式の変化を小さくする [88][123][157][158][124][114]
- 注意: (i) は**病変の転移そのものを抑える可能性**があり、主要検定の意味を変える。(ii) は T2 の課題の定義を変える。どちらも実験条件の変更で、人間の判断事項(`CLAUDE.md` §8)
- **推奨度: 中**(`logs/OPEN-ITEMS.md` の「★T2 の形の変化と #5」と同じ問い)

### 案 G: 機構の線を 1 本だけ足す(T1 と T2 で同じ部品を通るか)

- 中身: T1 と T2 の間で activation patching を行い、LoRA の効果が同じ成分を経由するかを見る。指標を複数併記し、休眠経路と自己修復を考慮する [22][146][145][144][77][159]

- **推奨度: 低〜中**(行動の平行性の解釈を強める唯一の直接手段だが、費用が大きい)

## 6. 最も退屈な対立仮説(`CLAUDE.md` §7)

> **LoRA が学んだのは「加算の規則」ではなく、「数を答える文脈で、答えを 2 だけ上にずらす」出力側の小さな変化である。T1 で interp に移ったのも、T2 で(1 本のシードで)移ったのも、減算に半分漏れたのも、規則の理解ではなくこの出力のずらしで説明できる。シードで割れたのは、そのずらしが文章題の出力経路に乗ったかどうかの偶然である。**

この仮説には文献上の足場がある。

- LoRA の FT 効果は「入力によらない定数の steering ベクトル」で説明できる、という報告がある(ワークショップ論文)。狭い FT の効果が rank 1 の LoRA や少数の線形方向・特徴で担われる、活性の差に読み取れる偏りとして残る、という報告も同じ向きである [56][57][58][84][88]
- FT は基盤の能力を書き換えず、出力側のラッパーを足すことが多い。LoRA が主に変えるのは応答の出だしやスタイルのトークンだという報告もある [8][59][60][116][78]

**この仮説を潰す手段と、いまの状態**

| 手段 | 状態 |
|---|---|
| 比較課題(数を出さないので出力のずらしでは答えられない) | **探索に落ちた**(§3.5) |
| `p2d`(定数のずらしでは表せない規則)の T2 への転移 | パイロット 1 本は T2 で崩れた。仮説と矛盾しないが、崩れの形なので支持もしない(§3.4) |
| `arb`(和を鍵とする任意の表)の interp | 未測定 |
| 乗算への漏れ(出力のずらしなら乗算にも漏れるはず) | `p2` は 0.033。**仮説の単純な形とは合わない**(§3.4) |
| 機構の線(案 G) | 無い |

**現時点で、この仮説への最大の防御は `p2d` の 10 シードである。**`p2d` が T2 で `p2` と同じ程度に移れば仮説は弱まり、`p2d` だけが崩れ続ければ仮説は強まる。後者の場合、「平行性」の結果がどうであれ、H0(統合された概念)の主張は難しくなる(解釈は人間)。
