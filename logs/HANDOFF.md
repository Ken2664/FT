### ★この環境で実際に踏んだ地雷(2026-09-06 その5)

- **`.md` を CRLF で書き戻す。**`.gitattributes` は `*.md text eol=lf` を宣言している。
  **★Edit 系のツールは環境によって CRLF に変換する。**`.md` を編集したら
  **必ず python でバイト単位の CR 数を数えて確かめること。**
  **grep で CR を数える書き方は展開に失敗して全行を数えることがあるので信用しない**
- **★`python -c "..."` の中にバッククォートを裸で書かない。**bash がコマンド置換として
  **`.md` ファイルをシェルスクリプトとして実行してしまう。**その結果、blockquote の行頭の
  リダイレクト記号が**リダイレクトとして解釈され、変な名前の空ファイルが作られる**
  (2026-09-06 に実際に起きた。空ファイル 2 件を作り、確認して削除した。
  追跡ファイルへの被害は無かった)。
  **★python は scratchpad に `.py` として書いて `python file.py` で走らせること**
- **大きな .md の差し込みは scratchpad に python スクリプトを書いて
  `newline=''` で読み書きするのが安全**
- **長い heredoc は一度に流さず、scratchpad に分割して書いてから結合する**
  (145 行の heredoc は bash のクォート解釈で落ちた)
- **`print()` に em dash や日本語を流さない。**この環境の Python の stdout は cp932 で落ちる
- **`cat > file <<'EOF'` のように `<<` の直後に空白を置かない形は落ちることがある。**
  `<< 'EOF'` と空白を入れる
- **表のセルの中のパイプ記号を `\|` にエスケープし忘れる**(`(1 \| condition:seed)` など)
