### ★この環境で実際に踏んだ地雷(その13 〜 その18 で確認済み)

- **★Bash ツールのヒアドキュメント(`python - <<'PY'`)はバックスラッシュを 1 段食う。**
  **2 個書いたものが Python には 1 個として届き、文字列リテラルが壊れて SyntaxError になる。**
  **バックスラッシュを含む置換は `chr(92)` で組み立てる。**その18 で 3 回踏んだ
- **★`git commit -m @'...'@`(PowerShell のヒアストリング)を Bash ツールで使わない。**
  **その18 で commit の件名に `@` が混入した。**
  **長いコミットメッセージは Python でファイルに落として `git commit -F <file>` で渡す**
- **★長い散文は Write ツールか、スクラッチに `.py` を書いて `python file.py` で差し込む。**
  **`cat > file <<'EOF'` は常に落ちる**
- **★`.md` を書き戻すときは newline を LF に明示する。**書いたらバイト単位で CR 数を数える
- **★`Edit` / `Write` ツールは CRLF を書くことがある。**`git add` の警告が出たら正規化する
- **★`sed` / `grep` の出力の日本語は化ける。`cut -c1-N` で切ると途中で切れて誤読する。**
  **文字列一致で編集するときは Python で `repr()` を見てから当てる**(その18 で 1 回踏んだ)
