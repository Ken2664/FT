### ★この環境で実際に踏んだ地雷

- **★`cat > file <<'EOF'` 形式の heredoc がこの環境の Bash ツールで落ちる。**
  **長い散文は Write ツールで一時領域に書き、python で本文に追記する**のが確実である。
  なお `python - <<'PYEOF'` に**スクリプトを流すのは動く**
- **★その `python - <<'PYEOF'` の中でバックスラッシュのエスケープが 1 段外れることがある。**
  その11 で `gsub("[\\r\\n]+", ...)` を R ファイルに書こうとして **実際の CR と LF が埋め込まれた。**
  **バックスラッシュを含む文字列を書くときは `chr(92)` で組み立てるか、Write ツールを使う**
- **★`.md` / `.py` / `.R` / `.yaml` を編集したら、必ず python でバイト単位の CR 数を数えて確かめること。**
  `.gitattributes` は `* text=auto eol=lf` を宣言している。Write 系は環境によって CRLF にする。
  **python で書き戻すときは `newline="\n"` を明示する**
- **★全角文字を混ぜない。★Markdown の入れ子太字(`****`)を作らない。**
  **その11 でも `。****検査1` を 1 箇所作って直した。**
  **追記するテキストだけを対象に、全角数字 / 全角括弧 / `\*{3,}` / `**` の偶奇を python で数える**
- **★`print()` に em dash や日本語や `≥` を流さない**(この環境の Python の stdout は cp932)。
  **その11 でも `χ²` を print して `UnicodeEncodeError` で落ちた。**
  検査スクリプトと検査用の python ワンライナーの出力は **ASCII だけ**にする
