## 3. ★問題 1: 二値群は、いまの素のモデルでは +2 病変をほとんど検出できない

### 3.1 何を計算したか(読み取りのみ。解釈はしていない)

`results/r8_fit_order6b/r8_fit.json` の当てはめ `logit P(y = 1 | θ) = β0 + β1·θ`(`y = 1` ⇔「和は閾値より小さい側」と答えた。ADR-079 決定1)を使い、
**「病変が内部の和を正確に +2 ずらし、比較がそれを完全に読む」という最も有利な仮定**のもとで、固定オフセット項目(gt は θ ∈ {0, +1}、lt は θ ∈ {+1, +2}。ADR-030 決定5)の
`rule_rate` が `ident` 比でどれだけ上がるかを出した(曲線を右へ 2 ずらす: `P(y=1|θ) − P(y=1|θ−2)`)。
あわせて、曲線が 25% から 75% まで上がるのに要る θ の幅(`2·ln3 / β1`)を出した。
計算のスクリプトは**付録 A**(R8 の当てはめをそのまま使う。`python <付録A>.py results/r8_fit_order6b/r8_fit.json`)。

- 一方 T1・T2 は、答えを桁で書くので**解像度は 1 単位**である(素のモデルの `correct` は 6 セルで 0.975〜1.000。[run:20260911_141547_order6_r1])

### 3.2 何を意味するか

1. **タスク型の間に、4 値分解の非対称(T14・★J)より桁違いに大きい「解像度の非対称」がある。**
   T1・T2 は ±1 を読み分け、T1b・T3 は ±20〜±3,500 を読み分けない。この差は既知性と無関係に**タスク型の主効果と交互作用をそれ自体で作る**。
   いまは適格性フィルタ(`ident` の `correct ≥ 0.70`)が二値の 6 セルを落とすので主要検定は守られるが、**その代わり主要検定は実質 T1 × T2(df = 2)になる**
2. **前段 FT が要る改善の大きさ**: 完全な伝播で 0.353 ロジットに届くには **β1 ≥ 0.18(25→75% の幅 ≤ 約 12)**、
   `rule` を 0.25 動かすには **β1 ≥ 0.5(幅 ≤ 約 4.4)** が要る(`2·β1·p(1−p)` の近似。p ≈ 0.5)。**いまの混ぜた当てはめより約 10〜800 倍鋭くする必要がある**
3. **鋭さが無いと、応答の偏りと病変を分けられない。**固定オフセットの項目は**真値が必ず「和は閾値より小さい側」、規則値が必ず「大きい側」**になる
   (判別可能であるための構成上の帰結。★F138 / PLAN-026 の `gt_yes_lt_no` の参照線)。したがって FT が「大きい側と答える」偏りを作れば、和を読まずに `rule_rate` が上がる。
   **β1 が 0.03 なら、偏りが 0.1 ロジット動くだけで交差点は約 3 単位動く** —— 病変の +2 と同じ大きさである。R8 の `Δ̂`(§4 順8・9)も同じ理由で、鋭さが無いと偏りと病変を分けられない
4. **Go/No-Go #2(`correct ≥ 0.70`)は鋭さの基準にならない。**固定オフセットの真値は全部「小さい側」なので、**「小さい側」と答える偏りだけで `correct` は 1.0 になる**(★F138)。
   前段 FT の成功基準(ADR-096 決定3)を #2 だけで書くと、**鋭さが無いまま合格しうる**

**心理物理学では、二値判断を「感度(傾き)」と「偏り(交差点)」に分けて読むのが定石である** [6][7][8][9]。
数の大小判断は差が小さいほど難しくなる(距離効果)[10]。LLM の内部の和は、大きさの近似と桁ごとの特徴の組み合わせで表されている [11][12][13][14][15] ので、
±1 の比較には「桁まで正確な和」を比較へ渡す必要がある。**中間結果を出力せずに次の演算へ渡す(潜在的な多段推論)は、LLM が苦手とすることが繰り返し報告されている**
[16][17][18][19][20][21]。

### 3.3 前段 FT(③-ii / ③-iii)への含意(案。人間が判断する)

- **③-iii(Yes/No の書式だけを訓練)は、T3 には効かない見込みが高い。**T3 の最初の出力位置の Yes/No の質量は**中央値 0.98 / 0.99**(★F139。[run:20260911_141547_order6_r1])で、
  **書式はすでに通っている。**T3 の問題は鋭さであり、書式の訓練はそれを直す経路を持たない。
  **T1b では**質量が中央値 0.0009 / 0.0004 なので、③-iii は**強制選択の採点を意味のあるものにする**効果はありうるが、鋭さは別問題として残る
  (**これはエージェントの推論であって実測ではない**)
- **③-ii(和を含まない比較を訓練)が効くかは、律速がどこにあるかで決まる。**明示された 2 数の比較がすでに鋭いなら、律速は「合成」であり、
  明示の比較を訓練しても内部で計算した和の比較へ移るとは限らない [16][20]。明示の比較も鈍いなら、③-ii に意味がありうる
- **ADR-092(両方を試す)は GPU と設計を約 2 倍にする。**上の見込みが正しければ、③-iii の腕は T3 について情報を生まない

### 3.4 診断(ADR-096 決定1)の設計への具体案

人間の案「足し算を含まない比較を T1b・T3 に対して確認する」を、**鋭さを測る形**にすると判定が一段で済む。

- **同じ書式で 2 本の心理測定関数を測る**: (A) 明示の比較 `x > y?`(和なし)/ (B) 和の比較 `a + b > θ?`(いまの T1b・T3)
- **差の範囲を広く取る。**R8 の窓(θ = −3〜+13)では、素のモデルの交差点が窓の外に出る(T3 `extrap_magnitude` の混ぜた当てはめで θ* = 177、gt で −467、T1b lt で −3,611)。
  **対数間隔で ±{1, 2, 3, 5, 10, 20, 50, 100, 300} のように広げ**、大きい和では相対差(Weber 比)でも並べる
- **判定規則の案**(値は人間が決めて、GPU の前に凍結する):
  - (A) が鋭く (B) が鈍い → **律速は合成。**③-ii の意味は薄い → §8 の P-4 の分岐へ
  - (A) も (B) も鈍い → **律速は比較そのもの。**③-ii を試す意味がある
  - どちらの場合も、**「+2 を読むのに要る鋭さ」(§3.2 の 2)を合否線にする**。`correct ≥ 0.70` だけにはしない
- 素のモデルの評価だけなので GPU は小さい(順6b と同程度の見込み。見積りは RUNNER)

### 3.5 見落とされている代替: 病変の大きさ(ADR-004)

- +2 を選んだ根拠は代数(群になる・単位元 −2)だったが、**代数を測る群(G2・G3)は ADR-024 D-2 で廃止された。**
  いま +2 の「小ささ」が、出力を経由しない課題(T3・T1b)の感度を決める拘束になっている
- 代数は任意のオフセット k で成り立つ(`code/tests/test_algebra.py`)。**k を比較の鋭さの尺度(数十)まで大きくすれば、ベースを変えずに**二値群の感度は上がる。
  ただし T1・T2 のデータ・`p2d` の定義・外挿の区分も変わり、偏り(§3.2 の 3)も残るので、**単純な解決ではない**
- **「ベースを変える(前段 FT)」と「病変を大きくする」は同じ問題への 2 つの解であり、後者はまだ比べられていない**、という指摘にとどめる

## 4. 問題 2: 「平行なら統合、平行でなければ別経路」は、そのままでは成り立たない

### 4.1 同じ「平行」が正反対の世界から出る

| 世界 | T1 の既知性の勾配 | T2・T3 | 主要検定(ロジットの交互作用) |
|---|---|---|---|
| A. 統合(和の表現が書き換わった)+ T1 に勾配あり | 落ちる | 同じ形で落ちる | **平行** |
| B. 統合 + T1 は全水準で規則どおり | 平坦に高い | 平坦に高い | **平行** |
| C. 表層(T1 の書式だけに貼った)+ T1 に勾配なし | 平坦に高い | `ident` の水準で平坦 | **平行** |
| D. 表層 + T1 に勾配あり | 落ちる | 平坦 | **非平行** |
| E. 統合だが、読み出しがタスクごとに非線形 | 落ちる | 別の形で落ちる | **非平行になりうる** |

- **B と C は正反対の仮説なのに、同じ「平行」を出す。**両者を分けるのは**転移の水準**(`p2` − `ident` を T2・T3 で見る)であって、勾配の形ではない
- **E は「非平行 ⇒ 別経路」を崩す。**1 つの潜在変数を別々の非線形な読み出しで見れば、どの固定リンクでも平行にはならない。
  **解離は別モジュールの証拠にならない**という議論は神経心理学で古くからある [22][23][24]
- `01_HYPOTHESES.md` の対応表は「交互作用が有意でない かつ `rule_rate` が裸の式でのみ高い → H0 寄り」と書いており、**B/C の問題を半分は認識している。**
  しかし `CLAUDE.md` §0 と `00_OVERVIEW.md` §1 は「平行性の検定が…判別する」と書いている。**事前登録の前に揃えるべき食い違いである**

### 4.2 確証的な構造が、事前登録した予測(H2)の側にだけ開いている

- **H2**(交互作用あり)を主予測として事前登録した(ADR-053 決定1)。主要検定が有意なら H2 を確証できる
- **H1**(統合)は主要検定が有意でないことを予測する。しかし (i) 「平行である」の TOST 境界は**未決**(`05_STATISTICS.md` §5)、
  (ii) ゲートキーピングにより、主要検定が有意でなければ §4 の順 1〜9 は**すべて探索的**になる(ADR-064 決定6 は順7 だけを門の外へ出した)
- **転移の水準**(人間の問い (2)(3) そのもの。「文章題に病変が乗ったか」)は、**確証的な評価項目として並んでいない**(Go/No-Go #4 は T1 × `id` だけ)
- **結果として、この設計は予測した H2 を確証する経路を持ち、その対立である H1・H0 を確証する経路をほとんど持たない**

### 4.3 案(人間が判断する)

- **推定対象を 2 つに分ける**:
  - **E1 転移**: タスク型 × 既知性ごとの `p2` − `ident`(と `arb`・`p2d`)。「転移しない」には TOST を当てる。**人間の問い (1)(2)(3) にいちばん直接に答える**
  - **E2 形の一致**: いまの交互作用。ただし「1 つの潜在変数で説明できるか」は**尺度に依らない state-trace 解析**で問うのが定石である [24][23][25][26][27]。
    条件(`ident`/`p2`/`p2d`/`arb`)× 既知性 × シードを点にして、T1 と T2 の `rule_rate` が単調な 1 本の曲線に乗るかを見る
- **最低限**、`CLAUDE.md` §0・`00_OVERVIEW.md` §1 の「判別する」を「H2 を {H0, H1} から分ける。H0 と H1 は転移の水準で分ける」に直すかどうかを、凍結の前に人間が決める

## 付録 A. §3.1 の試算のスクリプト(読み取りのみ。repo には置いていない)

```python
"""R8 の当てはめ(素のモデル・pilot)から、完全な +2 のずれが固定オフセット項目の y=1 率をどれだけ動かすかを試算する。
y = 1 <=> 「和は閾値より小さい側」と答えた(gt で No / lt で Yes)。P(y=1|θ) = σ(β0 + β1 θ)。
内部の和が +2 ずれると曲線は右に 2 ずれる: P'(y=1|θ) = σ(β0 + β1 (θ - 2))。
固定オフセット: gt は θ ∈ {0, +1}、lt は θ ∈ {+1, +2}(ADR-030 決定5)。どちらでも真値は y=1、規則値(t+2)は y=0。
よって ident の rule = 1 - P(y=1|θ)、p2 の rule = 1 - P'(y=1|θ)。差 = P - P'。
また、1/β1(ロジット 1 を動かすのに要る θ の幅)と、θ*±(ロジット ±1.1 ⇔ 25〜75%)の幅を出す。"""
import json, math, sys
sys.stdout.reconfigure(encoding="utf-8")
sig = lambda z: 1 / (1 + math.exp(-z))
d = json.load(open(sys.argv[1], encoding="utf-8"))
for run in d["runs"]:
    print(f"=== {run['run_id']} (arm={run['arm']}, pool={run['pool_id']})")
    for c in run["cells"]:
        for pol, thetas in (("gt", (0, 1)), ("lt", (1, 2)), ("mixed", (0, 1, 2))):
            f = c["crossing"].get(pol)
            if not f or f["kind"] != "fit":
                print(f"  {c['task_type']:4s} {c['coverage']:17s} {pol:5s} -- ({f['kind'] if f else 'none'})")
                continue
            b0, b1 = f["beta0"], f["beta1"]
            diffs = [sig(b0 + b1 * th) - sig(b0 + b1 * (th - 2)) for th in thetas]
            iqr = 2 * math.log(3) / b1  # 25%→75% に要る θ の幅
            print(f"  {c['task_type']:4s} {c['coverage']:17s} {pol:5s} beta1={b1:.3f}  1/beta1={1/b1:6.1f}  "
                  f"25-75%幅={iqr:6.1f}  完全な+2での rule の増分={sum(diffs)/len(diffs):+.4f}  (logit {2*b1:.3f})")
```
