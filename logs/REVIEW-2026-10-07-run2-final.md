## 2. 数の読み方(案。解釈は人間)

### 2.1 二つの別々の現象が重なって見える

**A. 当てはめ失敗**は `tau` が小さいほど多い(基本のシートで 29 → 25 → 22 → 15 → 6 → 3)。新しい項の分散が 0 の近く(境界)にあるときに、床で警告が残る、という形と合う(未検証。PLAN-042 の D1・D2 がこれを調べる)。
D2' のもとでは、これが棄却に数えられて門を閉じている(門の 4 点で、規則の棄却 30・23・31・34 のうち 25・22・27・29 が失敗)。

**B. 成功した当てはめの LRT の裾**は `tau` が大きいほど重い。5% の臨界値を超える割合は 0.042 / 0.067 / 0.013 / 0.035 / **0.085 / 0.103**、平均は 1.85 → **2.27 / 2.32**。
`tau` ≥ 1 の 2 点は 2·F(2, 18) の参照線(0.075・2.25)に近い。2 点を合わせると 18/191 = 0.094、CP95 [0.057, 0.145](算術)。
**PLAN-041 §3.5 が「新しい run の `tau` 0 の点で測る」とした量**の、最初の記述である(ただし `tau` 0 ではなく、seed × セルの分散が支配的になる `tau` ≥ 1 で見えている)。

- 理屈(案): `tau²`/10 がセル平均の item 由来の分散(`s2_item` 2.0 / 80 = 0.025)を上回ると、交互作用は少ない seed の水準で検定されるようになる。`tau` 0.25 では 0.006 < 0.025、`tau` 1.0 では 0.1 > 0.025。**ロジットの尺度と残差を無視した粗い算術**
- 構造のある誤指定(ii)(i)は、`tau` が小さくても裾が重い(平均 2.35〜2.76。per_cell 0.25 は 10/67)。D4 で足したシートが、**新しい項の形では吸収しきれない誤指定**として効いている見込み(ADR-124 の記録どおり「分散が交互作用の向きに集まり、量が多いとき」の限界の候補)

### 2.2 より退屈な仮説(`CLAUDE.md` §7)

1. **モンテカルロの揺れ**: 各点は成功 70〜97 本。`tau` 1.0 の 8/94 は CP95 [0.037, 0.161] で、0.05 も含む。B は「傾向」以上のことを言えない
2. **選択**: 成功だけの裾は、失敗した反復(`tau` が小さいほど多い)を抜いている。失敗した反復の `fit0` の χ² が大きければ、小さい `tau` の B は過小に見えている。**PLAN-042 の「失敗した反復だけの棄却率」(§2.2 の 3/4 行と `fit0` の感度)がこれを直接測る**
3. **ML の分散の過小推定**(glmer は ML / ラプラス): 2·F の参照よりさらに反保守的に出る向きの効果。`tau` 1.5 の 0.103 が 0.075 を上回るのはこれでも説明しうる(未検証)

### 2.3 (5) への含意(ここがいちばん大事)

ADR-127 決定7 の方針(過誤の門 = 失敗を非棄却に数えた無条件の率)を**このまま run2 の数に当てると**、門の 4 点の下端は 0.016 / 0.000 / 0.011 / 0.016 で、全部 0.075 以下になる。
**つまり門は開く。ただし、それで分かるのは「`tau` 0.25・0.5 では A を除くと過誤は膨らまない」ことだけである**。

- 門の点(`tau` 0.25・0.5)は、**A が支配的で B がほとんど出ない領域**にある(2.1 の理屈)。B が見えるのは記録だけの `tau` ≥ 1 と per_cell である
- したがって、**D2' を書き換えて門を開けることと、主要検定の過誤が保たれていることは別の話**になる。決定7 だけを (5) で実装すると、B を見ないまま門が開く
- ADR-127 決定6(規則を変えたら新しい反復で判定)は A の循環を防ぐが、**判定点の位置の問題は防がない**
- **HARKing の注意**: B は結果を見た後に見つけた。判定点を足す・検定を替えるなら、「見た後の追加」と記録し、**厳しくする向き**(点を足す・検定を保守的にする)に限るのが筋(案)
