反証・留保:

- **同じ basin か、別の basin か**: [16][17] は「事前学習から FT すれば同じ basin」とする。[2][15] は NLI の FT で別クラスタを見つけている。LoRA(低ランク・小さい lr)が、どちらに近い挙動をするかは文献からは決まらない(推論)。
- **分布単位で見るか、テスト集合で見るか**: [18] は、見かけの分散がテスト集合の有限性から来ると示した。本研究の文章題は項目数が有限であり、項目の分散と seed の分散を分けて推定する必要がある([3][4][8] も同旨)。
- **LLM の FT で「質的に別の戦略」を示した直接証拠は少ない**: [10][11] が示すのは性能・予測のばらつきまで。[19] は収束側の結果である。Betley et al. [36] の要旨にあるのは「同じモデルが場面により不整合に振る舞う」ことで、シード間の二峰性ではない(要旨の範囲での確認)。
- [12][13][14] は小モデルを一から学習した結果である。事前学習済み 8B の LoRA にそのまま外挿はできない。

## C2 狭い教師あり FT は、学習した写像が正しくても、書式の特化・汎用能力の忘却(応答スタイルの崩れ、破滅的忘却、alignment tax)を起こす

判定: **支持**。書式の特化は FT の最初期に起こるとする直接の証拠がある([21])。ただし大きな留保がある。性能低下の多くは知識の喪失ではなく、「タスクの推定・書式・整合」の崩れ(spurious forgetting)だとする系統がある([23][33][34][27])。LoRA は忘却が少ない([24])、FT 済み LM はほとんど忘れない([40])という反対側の結果もある。

## 本研究の設計への含意(事実と推論を分けて書く)

### 事実(文献の要旨で確認できた範囲)

- 分布内で同等の FT run が、分布外で大きく異なる汎化を示すことは、BERT の分類 FT で繰り返し報告されている。訓練損失が同じでも起こる([1][2][5][7])。算術・群演算の小モデルでは、初期化の違いが質的に別のアルゴリズムを生む([12][13])。
- LLM の FT でもシード分散は大きい([10][11])。一方、同一 basin・表現の収束を示す結果もある([16][17][19])。分散の一部はテスト項目の有限性から来る([18][3])。
- 狭い FT による書式の特化は、FT の最初期に起こると報告されている([21])。性能低下の多くは、知識の喪失ではなくタスク推定・整合・スタイルの変化だとする報告が複数ある([23][27][33][34])。
- 対策として、事前学習・汎用データの混合([30][53][54])、重み補間([55][26])、早期停止・チェックポイント選択([6][31])、分布での報告と区間推定([45][46][48][8])が挙げられている。

### 推論(人間の判断を要する。案であって決定ではない)

1. **seed は主要検定の実質的な標本単位である**。パイロットで seed 0/1 が文章題で正反対の挙動を示したことは、[1][2] の二峰性と同型である(親エージェントの伝達による。run_id 未付記)。そうであれば、混合効果ロジスティックモデルの seed ランダム切片(正規分布を仮定)は不適合になりうる。タスク型の効果に seed ごとのランダム傾きが要る可能性も高い。感度分析の案は次のとおり(採否は人間):
   - (a) seed 単位の要約、たとえば「文章題で規則を適用した seed の数 / 10」を、主要検定と並べて報告する。
   - (b) 項目 × seed の交差ランダム効果と、seed ごとのタスク型ランダム傾き。
   - (c) Multi-Bootstrap [8] または分布比較 [46]。
   - 交互作用の検出力は項目数ではなく seed 数で頭打ちになる、と読むのが自然である。
2. **`ident` 対照の文章題の低下は、「書式の特化 / spurious forgetting」として扱うのが文献上の第一候補である**([21][33][27])。§6 の 4 値分解のうち、`parse_fail_rate` と「数字だけだが正しい」の扱いが、病変の読みに直結する。書式に依存しない抽出規則が事前登録済みかどうかを確認するとよい(**仕様が曖昧になりうる箇所**)。主軸条件の文章題の rule_rate は、`ident` の書式変化と同時に起きているので、`ident` との差で読む必要がある。
3. **損失≈0 に数十ステップで達すること**と、書式の特化が FT 序盤で起こること([21][31][33])を合わせると、313–625 ステップの大半は損失≈0 のまま進むことになる。seed 0/1 の分岐がどの時点で起きたかは、保存済みのチェックポイントがあれば探索的に掃引できる([14])。seed 0 と seed 1 のアダプタ間の線形補間(LoRA のスケール掃引)は、二峰性が別 basin によるものかを安価に診断できる([2][15][55])。いずれも探索であり、主張には使わない。
