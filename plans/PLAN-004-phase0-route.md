2箇所で別々に生成すると、掃引と本実行で生成設定が食い違っても誰も気づかない。

   `null` のときは**例外で止める**。順2 が決まるまで実行できないのが正しい状態である

4. **`--dry-run` の出力に付いている警告文を本実行の出力に流用しない。**
   本実行の数値は実験結果であり、`results/` に書いてよい
5. **`runs/<id>/` の成果物は `infra/RUNPOD.md` §4 の一覧に従う**

   `predictions/` / `log.txt` / `cost.txt` / `token_boundary.json`)
6. **モデル名を config に書いてよいのは ADR-024(D-1)で決まっている
   `meta-llama/Llama-3.1-8B-Instruct` だけ。**`revision` は pull 時に埋める(ADR-031)
