### F6 ★ H3 の主予測を検定する段が、副次の階段に存在しない

**H3 の主予測**(`Documents/01_HYPOTHESES.md`):

> **主**: `id` セルでの `rule_rate` を揃えた時点で、`interp` の `rule_rate` が `p2` > `p2d`

これは **`p2` と `p2d` の条件間対比**である。ところが `Documents/05_STATISTICS.md` §4 の
副次的評価項目の階段(順1〜順9)に、**条件間で `p2` と `p2d` を比べる段は 1 つも無い。**

| 段 | 実際に何を比べているか | `p2` vs `p2d` か |
|---|---|---|
| 主要 | `p2` **内部**の `task:coverage` 交互作用 | 違う |
| 順1 | `p2d` **内部**の `task:coverage` 交互作用 | 違う(同じモデルを別データに当てるだけ) |
| 順2 / 順3 | 各タスク型内の単純効果 | 違う(§3.2「`data = primary` は `p2` 条件のみ」) |
| 順4 / 順5 | `p2` vs **`ident`** の TOST | 違う |
| 順6 | `p2d` 内部の `t_seen` vs `t_unseen` | 違う |
| 順7 | **`arb`** 内部の `id` vs `interp` | 違う |
| 順8 / 順9 | R8 の `Δ̂` | 違う |

**なぜ消えたか**: §4.1 の差し替え表は旧5(`p2` vs `p2d` の `interp`)を
「**新・順1 に吸収。単一セルの対比ではなく `p2d` の交互作用全体を見る形に強化した**」と記録している。
しかし **ADR-028 決定1 が定めた順1 は「`p2d` に対しても `p2` と同一の交互作用モデルを当てる」**であり、
**2 条件を突き合わせる検定ではない。**「吸収」の実体は**並置**である
(§3.2 の末尾も「`p2` と `p2d` の交互作用を**並べて論じる**際は…」と書いており、検定とは書いていない)。

**なぜ問題か**: 他の 2 文書は依然として条件間対比を予定している。

- `Documents/05_STATISTICS.md` §10 副次的評価項目:
  「**`p2` vs `p2d` の `interp` 差**(H3 の本体)★新設 | `p2` が 0.05 – 0.25 高い」
- `Documents/09_PAPER_PLAN.md` §5.5 / 図5:
  「**`id` を揃えた上での `interp` 比較**(`p2` vs `p2d` vs `arb`)。H3 の本体」★★

**このまま凍結すると、「予測は登録したが検定計画が無い項目」が事前登録に入る。**

**連動する既決事項(ここが重い)**: §4.1 は
「**旧5・旧6 が消えたため、階段の中で『`id` 到達度を揃える』対比は残っていない。
承認待ちの項目としても閉じる**」と書いて、**「`id` 到達度を揃える」の操作的定義を閉じている。**
段を復活させると **この操作的定義が再び必要になる**(暫定 0.90 という値が打ち消し線で残っている)。

### D2 `experiment.hypothesis` に何を入れるか

| 案 | 値 | 事前登録上の意味 |
|---|---|---|
| **A** | `H2` | **交互作用が有意であること**(統計的 `H_alt`)を主予測として宣言する |
| **B** | `H1` | **勾配が平行であること**(統計的 `H_null`)を主予測として宣言する |
| **C** | H 番号を入れず、`01_HYPOTHESES.md` の対応表への参照だけを入れる | **LRT が方向を持たない**ことに忠実。「何を予測したか」は弱くなる |

**判断の材料(いずれも既に repo にある記録であって、エージェントの意見ではない)**:

- `Documents/05_STATISTICS.md` §10「総合的な事前の見立て」(記入日 **2026-08-20**、実験実行前)は
  既に「**H2(部分的に概念的)が最も確からしいと予測する。H1 は支持されないだろう**」と書いている。
  `Documents/01_HYPOTHESES.md` の H1 節も「**H1 が完全な形で支持される確率は低い**」と書いている。
  **つまり repo には既に人間が書いた事前の見立てが存在する。**D2 はそれを config に写すかどうかでもある
- **案 B を選ぶと D3 が事実上強制される。**統計的帰無を予測することになるので、
  支持を主張するには TOST が要り(`CLAUDE.md` §2)、
  `05_STATISTICS.md` §5 の「勾配が平行である」の Δ を**実験前に**決めねばならない
- **ADR-052 で凍結した効果量 P1(非加法性 RMS = 0.353)を D2 の根拠に使わないこと。**
  ADR-052 決定2 は「**検出力の大きさ**を決めたのであって**どちらの形が起きると予測したか**ではない」と
  明記している。RMS > 0 は検出力設計の入力であって予測の宣言ではない

**★エージェントは推奨を出さない**(`CLAUDE.md` §8 / §2 の HARKing 禁止)。
