## 何を確かめる検査か

ADR-066 決定4 (d) は次の主張に乗っている ——
**`(0 + coverage | seed)` が run ごとに持つ `u_{s,k}` は 3 個で、タスク型に依存しない。
したがって、被覆水準の中でタスク型どうしを引き算する交互作用の対比からは消える。**
**ADR-066 のリスク欄が自分で「釣り合った線形モデルでは厳密だが、ロジスティックでは
一次の見立てにとどまる。確かめる前に断定形で書くな」と書いている**(`CLAUDE.md` §7)。

| 部 | 測るもの |
|---|---|
| **[A] 代数** | セル平均の 12 次元から 切片 + `task` 主効果 + `coverage` 主効果 を射影で落とし、残った交互作用の空間(rank 6)と `u_{s,k}` の負荷行列 `L` の積を見る。**0 なら、リンク関数によらず線形予測子の上で厳密に消える** |
| **[B] モンテカルロ** | 代数は**推定量の分散**については何も言わない(非恒等リンクではセルごとの情報量が `u` に依存するため)。同じ差分の差を経験ロジットと恒等リンクの 2 通りで作り、`sigma_u` を掃く |

## これは何ではないか

- **パイプラインのコードではない。**`code/` に置いていないのは意図的である
- **`pytest code/tests` の対象ではない。**回帰テストではなく一度きりの測定である
- **実データを読まない。GPU を使わない。**すべて合成データである
- **`glmer` の当てはめではない。**[B] はセルごとの経験ロジットから差分の差を作っている。
  **`lme4` の最尤推定量の SE が `sigma_u` にどう依存するかは、この検査では確かめていない**
- **ADR-066 を決め直すものではない。**モデル指定は変えない(`logs/HANDOFF.md`)

## 結果(2026-09-08。`run.log` が正本)

| # | 分かったこと |
|---|---|
| **F97** | **[A] は厳密である。**交互作用の空間(rank 6 = 主要検定の df)の**すべて**の対比について `\|c' L\| ` の最大値が **1.54e-15**(機械イプシロン)。対照に置いた被覆の主効果の対比は `[1, -1, 0]` を拾う。**`u_{s,k}` を受け取るのは被覆の主効果の勾配であって交互作用ではない**、が代数として確定した |
| **F98** | **[B] の期待値は消える。**差分の差の平均は `sigma_u` = 0 / 0.25 / 0.5 / 1.0 のどれでも 0.003 未満(真値 0) |
| **F99** | **★[B] の分散は消えない。**ロジットの SD は `sigma_u` 0 → 1 で **0.1659 → 0.1983(+20%)**。同じ構造の恒等リンクでは **0.0630 → 0.0637 で平ら**である。**「交互作用は `u` の影響を受けない」は一次の見立てであって厳密ではない** —— リンクが非恒等だと、セルごとの情報量が `u_{s,k}` を通るため |

**F99 の帰結**: `Documents/05_STATISTICS.md` §3.2 には
**「線形予測子の上では厳密に消える(F97)。釣り合った線形モデルでは推定量の分散にも入らないが、
ロジスティックでは分散に効く(F99)」**と書く。**「交互作用には一切影響しない」とは書かない。**
