# PLAN-019 検査2 のスクリプト(2026-09-09 に実行したもの)

**★F103-2(`(0 + coverage | seed)` の 6 パラメータをどう縮約して逆問題の横軸にするか)を、
人間が「選ぶ意味があるかどうか」で判断できるようにするためにある。**
ここに置いたのは、**数値の出所を後から監査できるようにするため**である(`CLAUDE.md` §2)。
検査1(`plans/PLAN-019-check1/`)と同じ作法である。

## 何を確かめる検査か

ADR-067(案 B)は「**どこまでの `s2_seed` なら 10 シードで検出力 0.8 に届くか**」を
逆問題として事前登録すると決めた。**逆問題には横軸が 1 本要る。**
ところが ADR-064 決定4 で seed の項は 3×3 の分散共分散(**6 パラメータ**)になったので、
**6 個をどう 1 本に潰すか**を先に決めないと横軸が定まらない(★F103-2)。

**検査1 は 3 つのセル平均を独立に引いていた**(`u = rng.normal(0, sigma_u, (N_SEED, N_COV))`)。
**これは「SD 等値・相関 0」という 1 つの縮約であって、中立な既定値ではない。**
検査1 は相関を動かしていないので、**F99 の +20% が `u` の共通成分(切片方向)から来たのか
差分成分(勾配方向)から来たのかを分離できていない。**
**★F103-1 案 (b)(シミュレータを `(1 | seed)` のまま据え置く)は、ちょうど「相関 = 1」の角であり、
一度も測られていなかった。**

この検査は**交換可能(compound symmetry)**な形で 2 次元に掃く。

```
Sigma = sigma^2 * [(1 - rho) I + rho J]        rho ∈ [-1/2, 1]
```

| 角 | 意味 |
|---|---|
| **`rho = 1`** | **`(1 | seed)` そのもの**(3 つのセル平均が一体で動く)= **★F103-1 案 (b) の DGP** |
| **`rho = 0`** | **検査1 の DGP** = **★F103-2 案 (a)**(SD 等値・相関 0) |

**平方根は Cholesky ではなく固有分解で取っている。**Cholesky は `rho = 1` で落ちるが、
**`rho = 1` はこの検査が存在する理由そのものの角だからである。**

## これは何ではないか

- **パイプラインのコードではない。**`code/` に置いていないのは意図的である
- **`pytest code/tests` の対象ではない。**回帰テストではなく一度きりの測定である
- **実データを読まない。GPU を使わない。すべて合成データである。実験結果ではない**
- **★`glmer` の当てはめではない。**セルごとの経験ロジットから差分の差を作っている。
  したがって**測っているのは 1 本の対比の SD であって、`df = 6` の LRT の検出力ではない。**
  **SD から検出力への写像はこの検査では確立していない**
- **★「6 パラメータを 10 シードから同定できるか」は測っていない。**
  ここは DGP を掃いているだけで、当てはめ側の不安定さ(ADR-059 の縮退が発火するか)は別の水路である
- **ADR-064 / ADR-066 / ADR-067 を決め直すものではない。**モデル指定は変えない

## 回し方

```bash
python plans/PLAN-019-check2/covariance_shape_check.py
```

`RNG_SEED` を固定してあるので**決定的**である。数十秒で終わる。出力は `run.log`。

**固定効果は検査1 と違う。**採択済みの効果量プロファイル P1 の共通部分
(`05_STATISTICS.md` §6.5 の `mu = 2.2` / `a` / `b`)をそのまま置いた。
**したがって SD の絶対値は検査1 と一致しない**(検査1 は `BASE_LOGIT = 2.0` / 別の `a`)。
比べてよいのは**膨張の比**のほうである。
