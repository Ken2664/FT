## 何を出したか

| 節 | 中身 | 種類 |
|---|---|---|
| **[A1]** | 1 項目 1 観測のとき、`s2_item` の profile 対数尤度が**完全に平ら**であること | **数値で確かめた恒等式**(周辺化 Bernoulli) |
| **[A2]** | 温度 0 の反復 3 回が**一致する限り**、対数尤度が `s2_item` について**単調に増える**こと | 同上 |
| **[B]** | k 水準から分散成分を推定したときの相対標本 SD = `sqrt(2/(k-1))` | **算術**(カイ二乗) |
| **[C]** | `s2_item` / `s2_tmpl` が `task:coverage` 交互作用へ**直接**入れる量。**対照として seed 項も測った** | **合成データ**(4,000 反復) |
| **[D]** | `s2_item` の寄与が `n_item` でどう縮むか(`M*` = 順5 と絡む) | 同上 |

## この検査が言えないこと(`CLAUDE.md` §7)

- **`glmer` を 1 本も当てていない。**したがって**検出力そのものは 1 つも出していない。**
  [C] / [D] が測るのは**セル平均のロジットずれ**であって、LRT の検出力ではない
- **[C] の対照行(seed 項が 0)を「seed の分散は検出力に効かない」と読んではいけない。**
  この検査が見ているのは**12 セル平均への直接の寄与**という 1 本の水路だけである。
  **`sigma` は二項抽出の水路(リンクの非線形性)で効き、それは検査2 が測った(F108)。**
  **本検査はその水路を持っていない。**言えるのは**非対称**である ——
  3 つの分散成分のうち、**交互作用へ直接入るのは `s2_item` だけである**
- **[C] の `s2_tmpl` = 0 は `draw_frame` の巡回割当の性質である**(ADR-069 決定4 (3))。
  **本番の項目集合でテンプレートが被覆水準間で不均衡なら、この打ち消しは成り立たない。**
  **本番の評価テンプレート集合(`data.eval_template_set`)は未確定である**(`STATE.md`)
- **[A2] は「反復が完全に一致する」極端な場合を置いている。**
  **実際の一致率は順6 のタスク5 が測るまで分からない**
- **[B] は正規のランダム効果に対するモーメント推定の算術である。**
  `glmer` の REML/ML 推定量そのものの分布ではない
