## 1. この PLAN が答える問い

**「素のモデルで、明示の 2 数の比較 (A) と和の比較 (B) は、+2 を読むのに要る鋭さに届くか。届かないのは合成(和を出さずに比較へ渡すこと)か、比較そのものか。」**

その答えで、次の段を凍結した規則(H2-2)どおりに決める: (A) は届き (B) は届かない → 律速は合成 → **前段 FT をせずに分岐**(ADR-097 決定4 (i))/ (A) も (B) も届かない → 律速は比較そのもの → **前段 FT(③-ii)に意味がある** / そのほかの組は H2-2 で決める。

## 3. 設計の案(**エージェントの案**。人間がレビューする = H2-6)

### 3.1 腕

| 腕 | 中身 | 文面(T1b / T3) | 役割 |
|---|---|---|---|
| **B** | 和の比較(いまの T1b・T3 と同じ文面) | 本番のまま(事実 h) | 合否線を当てる対象 |
| **A** | 明示の比較。**B と同じ組 (a, b)・同じ閾値 T・同じ極性で、`a + b` の部分だけを数 `x = a + b` に置き換える** | T1b: `{x}>{threshold}?` / `{x}<{threshold}?`<br>T3: `Is {x} greater than {threshold}? Answer Yes or No.` / `… less than …` | 合成を除いた比較そのものの鋭さ |
| **B-d**(H2-4 次第) | T1b の B に `Answer Yes or No.` を足す(順6b の (d) と同じ文面) | `{a}+{b}>{threshold}? Answer Yes or No.` | ★F139 の質量を除いた T1b の鋭さ |
| **A-d**(H2-4 次第) | T1b の A に同じ一文を足す | `{x}>{threshold}? Answer Yes or No.` | 同上の (A) 側 |

- **A と B を対にする理由(エージェントの見立て)**: 同じ (a, b, T, 極性) で、違いが「和を自分で出すか、数で与えられるか」だけになる。項目ごとに対にして比べられる。
  代案 = A の x を和と無関係に引く(対にならない。x の大きさの分布を別に揃える必要がある)
- **A と B の違いは「合成」だけではない**: 入力の長さ・トークン数・`+` の有無も違う(§6 の交絡 5)
- ① の前置き・(c) の較正の腕は**置かない**(ADR-097 決定1 に無い。S-① の T3 の質量が 0.001 台に落ちた = 事実 c)

### 3.2 組

- **案**: R8 と同じ組の選び方(極性を併合したセルから、組の水準のハッシュの小さい順)で、**(タスク型 × 既知性 × carry) ごとに `pairs_per_cell` 組**。T1b と T3 は別の組(R8 と同じ)
- `pairs_per_cell` の選択肢(H2-6): **20**(R8 と同じ組になる。R8 の曲線と並べられる)/ 40 / **80**(併合セルの全部)。ハッシュの順なので、20 の組は 40・80 の組の部分集合になる(事実 e の選び方から。**実装で確かめる**)
- 精度の目安(**算定。実験結果ではない**): 1 セル(タスク型 × 既知性)・1 極性・1 水準あたりの項目数は `2 × pairs_per_cell`(carry の 2 水準)。
  §3.5 の Δ₂(4 つの差の平均)の標準誤差は、**項目どうしの独立と p = 0.5 を仮定した概算で** 20 組で約 0.056、40 組で約 0.040、80 組で約 0.028
  (同じ組を水準の間で使い回すので、実際の値は相関の向きで上下する)

### 3.3 差の水準(θ = T − t)

- **案 L1**: θ ∈ {0, ±1, ±2, ±3, ±5, ±10, ±20, ±50, ±100, ±300}(19 水準。監査 §3.4 の例に 0 を足した)。**{−2, −1, 0, +1, +2} を必ず含む**(§3.5 の Δ₂ が要る)

- 代案(H2-6):
  - L2 = L1 の負の側を `−(t − 1)` で打ち切って 1 点にまとめる(組ごとに水準が変わる)
  - L3 = `extrap_magnitude` に相対の水準(θ = ±round(r·t)。例 r ∈ {0.005, 0.01, 0.02, 0.05, 0.1, 0.2})を足す(監査 §3.4 の「大きい和では相対差でも並べる」)。**合否線の原理(+2 は絶対の差)には使わず、記述に置く**(エージェントの見立て)
