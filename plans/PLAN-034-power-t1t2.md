## 4. 人間が決めること(★推奨は手続き・整合性・費用からのもの。結果の読みではない)

| **D1** | P1 を df = 2 でどう使うか | ★(a) **RMS = 0.353 を保つ**: T1・T2 の 2 行の加法部分はそのまま、delta だけを同じ形で √(2/3) ≈ 0.8165 倍(§5.1)/ (b) T1・T2 の 2 行をそのまま使う(RMS 0.432)/ (c) RMS の格子で掃く | ADR-052 が凍結したのは「下限 RMS = 0.353」。(b) は宣言より大きい効果しか見ず、検出力を高めに出す。(a) は新しい値を作らない(倍率は算術で決まる)。(c) は本数が格子の数だけ倍になる |

## 7. 想定される交絡と罠

1. **パイロットを見た後の追加**: D5・D6・D7 の動機はパイロットの二峰と天井(レビュー §3.2・§3.6)である。採るなら ADR にその事実を書く。**パイロットの数値を DGP の値に使わない**(D7 の `tau` も `sigma` の格子の流用で、パイロットから推定しない)
2. **D7 の誤指定は「§3.2 を変えるべきか」を測るだけ**。α が膨らむと出ても、**ランダム構造の変更(例: seed × task の傾き)は凍結前の別 PLAN で人間が決める**。この PLAN の中で §3.2 を直さない
3. **TOST の Δ を合成データの曲線を見て決めること**は実験データを見ることではないが、**「検出力が足りる Δ を選ぶ」形になると SESOI の意味が逆転する**。Δ を決める ADR には「何を無視できる効果とみなすか」の理由を先に書く
4. **D1 (a) で T1・T2 のセルの値が変わる**(T1 × id 0.94 → 0.945 など)。§6.5 の表の値ではなくなるので、照合門(`rule_rate`)は §6.5 の表ではなく `eta` から作る。§6.5 の表は書き換えない
5. **`sigma*` の数値は `s2_item` / `s2_tmpl` が決まるまで論文にも事前登録の本文にも書かない**(§6.7 の脚注のまま)
6. **天井**(D9): 実データでセルが 1.000 に近いと、`glmer` の当てはめが分離に近づき、ADR-059 の縮退が想定外に発火しうる。このシミュレーションの P1・P0 は天井を含まないので、その振る舞いは測れない(限界として書く)
7. **ADR-095 決定2 の取り下げ**(D3 (a))は主要検定についてだけ。探索の T1b・T3 の検出力を後で出すなら、その時に実装する
