## 5. 判断材料(★仮定値からの近似・小検査。実験結果ではない。出所は `plans/PLAN-034-check-prerun/`)

### 5.1 何が検出力を決めているか(F1・F2)

- 近似(Wald。`approx_power.py`): `sigma` 0〜1.5・`rho` 0 / 1 のすべての点で 0.617〜0.632
- 本物の経路の小検査(`check_p1_summary.json`。32 反復・モンテカルロの SE ≈ 0.086): `sigma` 0 → 0.625 / 1.5 → 0.625
- `s2_item` × `n_item` の近似の表は `plans/PLAN-034-check-prerun/README.md` F2(**値の提案ではない。D1 の格子は人間**)
- `n_seed` を増やしても項目の分散は減らない(近似: 5 → 0.52 / 10 → 0.63 / 40 → 0.75)

### 5.2 費用(★推算・小検査からの外挿)

- 小検査: 64 ペア(P1・`rho` 0・`sigma` ∈ {0, 1.5} × 32 反復)が 16 並列で壁時計 27.5 分(スクラッチパッドで実行)
- `--dry-run` の見積り(ADR-121 の記録): 32 点 × 1000 反復 = 32,000 ペア・16 並列で約 138 時間
- 1 ペアの時間は表の行数(= `n_item` に比例)にほぼ比例すると仮定している(未実測)。**`n_item` を倍にすると 1 ペアもほぼ倍**
- シートの点数の比: P1 12 / P1⁻ 2 / P0 12 / 誤指定 6(誤指定は全体の 6/32 ≈ 19%)

### 5.3 誤指定(F4)

- 近似の第一種の過誤: `tau` 0 → 0.050 / 0.5 → 0.168 / 1.0 → 0.445 / 1.5 → 0.655(`approx_misspec.py`)
- **F1 の裏返し**: seed の効果がタスク型に共通なら交互作用で消えるが、タスク型ごとに違えば(`tau` > 0)§3.2 はそれを項目の誤差として数える

## 7. 想定される交絡と罠

1. **`n_item` の格子を検出力の曲線を見てから選ぶと、「足りる値を選ぶ」形になる**。格子は本実行の前に人間が §11 に書く
2. **検出力分析の `n_item` と実際の `eval.cells` は別物**。曲線が「80 では足りない」と出ても、評価の項目数を変えるのは S5 の人間の判断(実験条件。`CLAUDE.md` §8)。プールがセルあたり何件まで埋まるかは**未確認**
3. **D3 (a) の「膨らむ」の判定は、誤指定の結果を見る前に閾値を書く**(見た後に決めると事後選択)
4. **F1 の構造の議論は §3.2 の DGP の中でだけ成り立つ**。誤指定(`tau` > 0)があれば `sigma` に相当する量が効く。誤指定の結果で §3.2 を変えたら、軸の見直しもやり直す
5. **小検査の `sigma` = 0 では縮退が 32/32 で発火した**(F6-8)。`sigma` の確認点に 0 を入れると、縮退した当てはめの検出力を測ることになる
6. **近似の数(§5)は判断材料で、本実行の結果ではない**。文書・論文に書かない
