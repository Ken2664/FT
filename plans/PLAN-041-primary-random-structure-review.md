## 3. 検定の解釈(案。解釈の確定は人間。`CLAUDE.md` §8)

### 3.1 事前に決めた規則が言うこと(確証的な読みはこれだけ)

- `n_item` 80・100 反復で、`tau` 0.25 → 14/100(95% CI 下端 0.0787)・0.5 → 15/100(0.0865)。両方とも 0.075 を超えた → **「§3.2 の当てはめは、seed × task × coverage の変動が `tau` 0.25〜0.5(ロジット)あると、主要検定の第一種の過誤を名目の 1.5 倍より上に膨らませる」**[run:20261004_120002_power_sim_t1t2]
- 規模の感覚: `tau` 0.25 はロジットの SD で、`s2_item` = 2.0(SD 1.41)の 6 分の 1 程度の小さな変動である。**小さな seed × セルの変動で門が閉じた**
- **この読みは §3.2 の DGP の中の話である**(実データの `tau` は分からない。§3.6)

### 3.2 機構 (a): 検定する交互作用のシード間変動がモデルに無い

- §3.2 の `(0 + coverage | seed)` は run ごとに被覆 3 水準の値を持つが、**タスク型に依らない**ので交互作用の対比では打ち消される(ADR-066 決定4 (d)。F97)。**交互作用のシード間変動は誤差に畳まれる**と §3.2 自身が書き、10 シードでは置かないと決めていた(ADR-066)
- 混合モデルの文献は、**検定する効果について単位(ここでは seed)ごとの変動を置かないと、その効果の検定が反保守的になる**ことを一貫して報告している [1][2][3][4][5][9](ただし [4] の主眼は、最大構造が検出力を失うことのほう)。交差・入れ子のレベルをまたぐ交互作用に固有の注意もある [3]
- **算術による見込み**(仮定値からの近似。実験結果ではない。F4 と同じ計算): 交互作用の差分の差(4 セル)の分散を、`z` が無いとき `V0` ≈ 0.145(項目 `s2_item / n_item` = 0.025 × 4 + 二項の分散 ≈ 0.045。P0 の `eta` から)、`z` が足す分を `4 tau² / 10` とすると、χ² は約 `k = 1 + 0.4 tau² / V0` 倍に膨らみ、棄却率 ≈ `exp(−5.991 / (2k))`

| `tau` | 近似の棄却率 | 観測(全体) | 観測(`drop_item` を除く・条件付き) | 観測の χ² の平均 / 近似の 2k |
|---|---|---|---|---|
| 0 | 0.050 | 10/100 | 5/84 | 2.55 / 2.00 |
| 0.25 | 0.078 | 14/100 | 7/87 | 2.99 / 2.35 |
| 0.5 | 0.170 | 15/100 | 10/92 | 3.39 / 3.38 |
| 0.75 | 0.31 | 38/100 | 32/93 | 6.86 / 5.10 |
| 1.0 | 0.45 | 53/100 | 44/90 | 9.82 / 7.52 |
| 1.5 | 0.66 | 73/100 | 69/96 | 18.86 / 14.4 |

- **読み(案)**: `tau` ≥ 0.5 の膨らみは、項が無いことだけでおおむね説明がつく大きさである。`tau` ≥ 0.75 では観測が近似より大きい。原因の候補は、10 シードでの LRT の漸近 χ² の反保守性 [24][25][26][27][31] と、ロジットの非線形(F99)である(どちらも未検証)
- **機構 (a) は、縮退カスケードを直しても残る**(`drop_item` を除いても `tau` 0.75 で 32/93)

### 3.3 機構 (b): 縮退の最後の段が item を落とす

- 縮退順序(ADR-065 決定2)は template → coverage の傾き → **item**。最後の段 `(1 | seed)` だけの当てはめは、**item の分散 `s2_item` = 2.0(このモデルで最大の分散成分)を誤差から外す**
- item は task × coverage のセルに入れ子なので(§3.2 の `(1 | item)` の欄)、**セルの差は item の標本で決まる**。item を固定扱いにすると、条件の差の検定が反保守的になることは古くから知られている [1][7][11][13][14]。**item が条件に入れ子の設計を本文で扱っているのは [1] だけ**(SCOUT。[11] は書誌のみ確認)
- 観測: `drop_item` まで落ちた当てはめは `tau` 0 で 5/16、0.25 で 7/13、0.5 で 5/8 棄却(by_reduction.json)。**`tau` 0 の較正点の 10/100 は、ほぼこの段から来ている**(除くと 5/84)
- **注意(条件付きの値)**: 「`drop_item` を除いた率」は、**`drop_item` に落ちた反復を捨てた条件付きの率**であって、「item を落とさない手続きの率」ではない。落ちた反復は、手続きを変えれば別の段で当てはまり、別の χ² を出す。**除いた率で門を読み直してはならない**(門の判定は変えない)

### 3.4 なぜ縮退がこれほど起きるか(未確定)

- 600 本のうち 312 本が `drop_coverage_slope`、58 本が `drop_item` まで落ちた(by_reduction.json の段ごとの `n` の合計。全 `tau`)。**途中の段でどの判定が発火したかは記録に無い**(fit の JSON は最後の段の判定だけを持つ)
- ADR-059 の閾値(logLik の改善 < 0.001 かつ max|Δβ|/SE < 0.01)は合成データ 34 ペアの実測から決めたもの。**4,800 行の 2 値の当てはめで厳しすぎるかは分からない**。収束しないときの扱いの指針は [1][17][18][19][20][21]。**収束の警告の偽陽性を確かめた査読論文は SCOUT では見つからなかった**
- → §4 D5 で、次の run から各段の判定を記録する案を出す(**原因が分かる前に閾値を変える案は出さない**)

### 3.5 小さいクラスタ数での LRT

- seed は 10 水準である。**クラスタ数が少ないとき、固定効果の LRT を漸近 χ² で読むと反保守的になりうる**ことが報告されている [24][25][26][27][31]。代替はパラメトリック・ブートストラップの LRT [24] など。**ただし直接の根拠はすべてガウスの LMM で、2 値の GLMM で少数クラスタの LRT を調べた文献は SCOUT では見つからなかった**。また [29] は適切な自由度で推論が直ると述べ、[30] は固定効果の SE は偏らないとし、[1] は典型的な規模では問題になりにくいとする(主張を限る側の文献)
- 機構 (a) を直して seed × セルの項を置くと、交互作用は**この項の分散に対して**検定されるようになる(古典的な分割区画の分散分析なら誤差の自由度は (10 − 1) × (2 − 1) × (3 − 1) = 18)。このとき漸近 χ² がどれだけ外れるかは**未実測**で、新しい run の `tau` 0 の点で測る

### 3.6 `tau` > 0 は現実的か

- 同じモデル・同じデータでもシードだけで FT の結果、**とくに分布外・汎化の振る舞い**が大きく変わることは繰り返し報告されている [32][33][34][36][39](ほとんどが BERT 規模の分類。**LLM の LoRA FT でシード × 条件の変動を測った文献は SCOUT では見つからなかった**)。この研究の T2(文章題)・`extrap_magnitude` はまさにその側にある
- パイロット FT の二峰(ADR-114 の記録)も同じ向きの観察である。**ただしパイロットの数値から `tau` を推定しない**(2 シード。PLAN-040 D7 (a))
- → **`tau` = 0 を前提にした主要検定は、事前登録として弱い**(読み。案)

### 4.1 聴取の場で直した草案の穴(★2026-10-05 その150。エージェント (PLANNER, Opus 5.5) が聴取の前に見つけてチャットで示した)

3. **D4 の大きさの揃え方で門の結果がほぼ決まる**(§5.4)。最初に推奨した「セルあたりの平均分散 = `tau²`」(下の (i))は、検定する部分空間の分散を今のシートの 3 倍にする。→ 改めて諮り、人間は「(ii) で判定し (i) は記録だけ」を選んだ(§10 D4)
