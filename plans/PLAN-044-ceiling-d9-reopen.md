## 3. 天井のシートの設計

### 3.1 何を測るか(点ごと。**すべて記述で、門の判定には使わない**。Q3)

| 量 | 中身 | 既存か |
|---|---|---|
| 当てはめ失敗率 | `allFit` の段の後も収束しない反復の割合と CP95 | 既存(`failed_rate`) |
| 着いた段の分布 | 0〜3 段 / `allFit` で救われた / 失敗、の件数。`singular` の率 | 既存(`levels`・`singular_rate`) |
| 棄却率(無条件) | 失敗を非棄却に数えた LRT の棄却率と CP95 | 既存 |
| 棄却率(条件付き・記述) | 成功した反復だけの棄却率 / 失敗した反復の `p_value_failed_descriptive` の棄却率 | 既存(PLAN-043 罠2: 並べるだけ) |
| 交互作用 2 係数 | 推定値と SE の分位点(成功した反復) | 既存の出力から集計を足す |
| TOST | 「同等と言える最小の Δ」の分位点(失敗 = +∞) | 既存(`tost_min_margins`) |
| **真値(ロジット)** | DGP の交互作用 2 係数。天井が厳密な 1.000 なら「定義されない」と書く | **新規** |
| **真値(確率の尺度)** | DGP の周辺確率(ランダム効果で積分)で作った差の差 2 つ | **新規** |
| 観測のセル率 | 反復ごとの 6 セルの `rule_rate`(表から数える) | **新規**(表は `--keep-frames` で残す) |

### 3.2 シートの形(Q2)

すべて `n_item` 80・`sigma` 1.0・`rho` 0・`tau` 0(P1・P0 の主の軸の点。`configs/power_sim.yaml` の `report.n_item_axis`)。天井の水準 `L` は §3.3。

| シート(案) | DGP の `eta`(T1 の行 / T2 の行) | ロジットの真値 | 何を見るか |
|---|---|---|---|
| **`ceiling_p0`**(置き換え) | P0 の T1 × `id`・`interp` を `L` に置き換え: T1 = [`L`, `L`, 0.6] / T2 = P0 のまま [1.8, 0.8, −0.4] | 平行でない。(interp − id) の係数 = −1・(extrap − id) の係数 = `L` − 2.8 で、`L` とともに増える。`L` = +∞ なら定義されない | **パイロットの形**(T1 だけが天井で、T2 は天井でない)での失敗率と棄却率。棄却がロジットの尺度では「正しい」のに、天井だけで作られているかを、確率の尺度の真値と並べて見る |
| **`ceiling_p1`**(置き換え) | P1 の T1 × `id`・`interp` を `L` に置き換え: T1 = [`L`, `L`, 1.138832] / T2 = P1 のまま | 同上(P1 の交互作用に天井が重なる) | 天井が P1 の効果の検出を壊すか(失敗率・TOST) |
| **`ceiling_null`**(T1 の行をずらす) | P0 の T1 の行全体に `c` を足す。`c` = `L` − 2.8(T1 × `id` が `L` になる): T1 = [`L`, `L` − 1, `L` − 2.2] / T2 = P0 のまま | **厳密に加法**(平行。帰無が真) | 天井の近くで帰無が真のとき、LRT の第一種の過誤と失敗率がどうなるか。`L` = +∞ は T1 の行が全部 1 になり情報が無いので置かない |

- **`ceiling_p0` と `ceiling_null` は同じ帰無ではない。**天井のときに「ロジットの尺度で平行」な DGP は、T1 の `extrap_magnitude` まで天井に近づける(`ceiling_null`)か、T2 の差を無限に開く形しか作れない。**パイロットの形(T1 の `extrap_magnitude` は天井でない)は、ロジットの尺度の帰無とほぼ両立しない。**これは D.0 の言い換えで、シートを 2 種類に分ける理由である
- T2 の行はどのシートでも P0・P1 の仮定値のままにする。**パイロットの T2 の二極化(R2)は入れない**(ADR-130 決定2。S4 の後)

### 3.3 天井の水準 `L` と値の出所(Q1)

**値の出所はパイロットの 2 シード(PLAN-001 §4.6 規則4)しかない。しかもパイロットが言えるのは下限だけである。**

- 80/80 の Clopper–Pearson 95% 区間の下端は 0.95494(ロジット 3.054)。2 シードをまとめて 160/160 と数えると 0.97721(ロジット 3.758)である(2026-10-15 に `scipy.stats.beta` で計算した算術)。**2 シードは同じ 80 項目を解いている**ので、160 個は独立ではない。下端は 0.955 と 0.977 のあいだにあると読む
- 上端は 1.000 そのもの(厳密な天井)である。**パイロットは「1.000 に近い」と「1.000 そのもの」を区別しない**
- `eta` の値は、ランダム効果(`sigma` 1.0・`s2_item` 2.0・`s2_tmpl` 0.5)を足す前の値である。周辺の率は `eta` の逆ロジットより下がる。だから、`L` を周辺の率から決めるか、「パイロットの観測が起こる確率」から決めるかで値が変わる(Q1)

**★推奨の決め方(Q1 (a))**: 次の 3 水準を置く。

| 水準 | 定義 | 意味 |
|---|---|---|
| `L_05` | シートの DGP(`sigma` 1.0・`s2_item` 2.0・`s2_tmpl` 0.5・`tau` 0)の下で、「パイロットと同じ形の観測(2 シード × 80 項目で、T1 × `id` と T1 × `interp` の両方が全部 rule)」が起こる確率が **0.05** になる最小の `L` | パイロットと矛盾しない境界(この確率が 5% を切る `L` は、パイロットの観測と両立しにくい) |
| `L_50` | 同じ確率が **0.5** になる最小の `L` | パイロットの観測が「よくある」水準 |
| `L_inf` | `L` = +∞(T1 × `id`・`interp` の `is_rule` は常に 1) | パイロットが文字どおり示す状況 |

- `L_05`・`L_50` は**仮定値と規則だけで決まる関数**で、パイロットの点推定は使わない。実装(I3)が固定の乱数種で計算し、出力と計算のスクリプトを残し、**当てはめの前に config に書いて commit する**。値はこの PLAN では書かない(まだ計算していない)
- `ceiling_null` の `L_05`・`L_50` は、`ceiling_p0` と同じ値を T1 × `id` に使う(T1 × `interp` は 1 低くなるので、パイロットの形の観測が起こる確率は定義より低い)

## 8. 想定される交絡と罠

- **罠1(パイロットを DGP に入れる)**: パイロットの T1 × `extrap_magnitude`(0.825・0.588 など)や T2 の値を、天井のシートの他のセルに使わない。天井の水準も点推定ではなく、§3.3 の規則(パイロットと矛盾しない境界)で決める

- **罠4(選択の偏り)**: 成功した反復だけの係数・TOST を「天井でも推定できる」と読まない。失敗率と並べる(PLAN-043 罠2)

- **罠6(run3 との混同)**: 天井のシートの失敗率で run3 の門を判定しない。run3 の config・`rng_seed` 20261008 は変えない
