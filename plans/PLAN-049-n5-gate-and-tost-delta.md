### 3.3 算術(設計の性質。実験結果ではない。§4 Q4 の材料)

2 係数を `c1`・`c2`、セルの効果を `e = (0, c1, c2)` とすると、D3 の定義から

- `RMS = ½ · sqrt(Σ_j (e_j − ē)²)`。P1(D1 (a))で 0.352767 になり、D2 と一致する(この節の検算)
- `|c1| ≤ Δ` かつ `|c2| ≤ Δ` の正方形の中で RMS が一番大きいのは角 `(Δ, −Δ)` で、**RMS の最大値 = Δ / √2**
- したがって **Δ = √2 × 0.352767 = 0.498888** のとき、「同等」の領域にある交互作用はすべて RMS ≤ 0.352767(検出したい下限)に収まる。逆に、RMS が下限以上の交互作用は、どの形でも一方の係数の絶対値が 0.498888 以上になる

| Δ(ロジット) | 「同等」の領域の中の RMS の最大値 | 下限 0.352767 との関係 |
|---|---|---|
| 0.25 | 0.1768 | 下限の半分 |
| 0.49 | 0.3465 | 下限より小さい |
| **0.4988** | **0.3527** | **下限の内側(切り捨て)** |
| 0.50 | 0.3536 | 下限をわずかに超える |
| 0.6931(= log 2。オッズ比 2) | 0.4901 | 下限を超える |
| 1.0 | 0.7071 | 下限の 2 倍 |

(計算は Python。`sqrt(2) × 0.352767` と `Δ / sqrt(2)`。値の検算は採択後に実装でテストに固定する)

### Q1. 解析門を主要検定(T1 × T2)に掛けるか

| 案 | 中身 | 長所 | 短所 |
|---|---|---|---|
| **★(a) 主要検定は門なしが主。門ありは感度解析(探索)** | 主要検定は `p2` の 10 run すべてで当てる(§2 の書き方のまま)。門を通った run だけで同じ手続きを当てたものを感度解析として併記する(Holm に入れない) | §2 の前処理を変えない(G3)。**主要検定の基準セル T1 × `id` で run を選ばない**ので ★C(G7)と G8 の偏りを主要検定に持ち込まない。シード数の検査(G9)を変えなくてよい。門は run 単位なので、門が何も落とさなければ主と感度は同じ結果になる | 順1b(門ありが主。G2)と向きが逆になるので、理由を ADR に書く必要がある。病変が入らなかった run も主要検定に入る(床の run が当てはめに入る) |
| (b) 順1b と同じく「門ありが主 + 門なしが感度」 | ADR-055 決定3 を主要検定にも広げる | 順1b と揃う。病変が入らなかった run を主要検定から外せる | ★C・G8 を主要検定に持ち込む(従属変数の基準セルで選ぶ)。シード数が 10 未満になったときの規則(Q3)が要る。§2 の書き換えになる |
| (c) 門を「落とす」でなく「止める」に使う | 門を割った run が 1 本でもあれば、主要検定は「実施不能: 解析門」と報告する(または、事前に決めた規則で run を作り直す) | 解析の中で従属変数による選別をしない | 作り直しは GPU が要り、その規則もまた選別になる。止めるだけなら、1 本の失敗で主要検定が出ない |

**推奨 (a) の理由**: 主要検定が問うのは「勾配が T1 と T2 で平行か」であり、T1 × `id` はその基準セルである。そのセルの `rule_rate` で run を選ぶと、選ばれた run では T1 × `id` が高い側に寄り、T1 の勾配だけに選別が掛かる(G8)。パイロットの `p2` 2 本は T1 × `id` が 1.000 だった(G11。主張には使わない)ので、門が実際に run を落とす場面はおそらく少ない。それでも、落とした場合に主要検定の推定量が変わる経路は塞いでおくほうがよい、という理由。**順1b の門(ADR-055 決定3)はこの Q では変えない。**

### Q4. 平行性の TOST の Δ の値

| 案 | Δ(ロジット) | 「無視できる効果」の理由 | 長所 | 短所 |
|---|---|---|---|---|
| **★(a) Δ = √2 × 検出したい下限の RMS = 0.4988(4 桁で切り捨て)** | 0.4988 | 「同等」の領域にある交互作用は、どの形でも RMS が下限 0.353(ADR-052 決定2。「これより小さい非加法性は検出しなくてよい」と既に凍結した値)を超えない(§3.3) | 新しい値を作らず、既に採択した SESOI(ADR-052)から算術で決まる。罠3 を避けられる(曲線を見ずに決まる)。§5 の「1 行目は順6 に依存しない・P1 / P2 から決まる」とも合う | 10 シードで「同等」と言えるかは run3 の D5 の表を見るまで分からない(言えない公算もある)。IUT は保守的 |
| (b) Δ = 0.25 | 0.25 | 下限の半分より小さい交互作用だけを無視する | 「同等」の主張が強い | 出所が無い。10 シードでは、ほぼ言えない公算が高い |
| (c) Δ = log 2 = 0.6931(オッズ比 2) | 0.6931 | 慣用の大きさ | 言いやすい | 「同等」の領域に RMS 0.49 までの交互作用が入り、ADR-052 で「検出したい」とした大きさを「同等」と呼びうる(SESOI と矛盾する) |
| (d) Δ を決めず、最小の Δ だけ報告する | — | — | 値を決めなくてよい | 主要検定が有意でないとき「平行」と書けない(`CLAUDE.md` §2)。ADR-138 決定3 は Δ を凍結前の未決としている |

**推奨 (a) の理由**: Δ を新しく選ぶのではなく、既に凍結した「検出したい下限」と同じ境界を、TOST の正方形の領域に写すだけである。切り捨てるのは、領域が下限を少しでも超えないようにするため(0.50 だと角の RMS が 0.3536 になり下限を超える。§3.3)。
